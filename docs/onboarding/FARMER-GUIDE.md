# Farmer Onboarding Guide

Welcome to the farm system. This guide gets you connected to the tools you'll use day-to-day.

---

## Step 1 — Join the network

All farm tools run on a private network (Tailscale). You need to be on it before anything works.

1. Install **Tailscale** on your phone or laptop:
   - iPhone / iPad: App Store → search "Tailscale"
   - Android: Play Store → search "Tailscale"
   - Laptop: tailscale.com → Download

2. Open the app and tap **Log in**

3. When it shows a QR code, tell whoever is onboarding you — they'll scan it or share the link with you

4. Once approved, you're in. The app should show you as connected.

---

## Step 2 — Bookmark these links

Open these in your browser once you're on Tailscale:

| Tool | Link | What it's for |
|---|---|---|
| **Mission Control** | http://100.96.10.66:8080 | Live sensor readings, charts |
| **farmOS** | http://100.96.10.66:8082 | Farm records, logs, assets |
| **Logger** | http://100.96.10.66:8765 | Quick observation logging via QR |

If any of these don't load, make sure Tailscale is connected (check the app).

---

## Step 3 — Log in to farmOS

Go to http://100.96.10.66:8082/user/login and use the credentials your admin gave you.

---

## That's it

If something isn't working, message the admin on Signal.
