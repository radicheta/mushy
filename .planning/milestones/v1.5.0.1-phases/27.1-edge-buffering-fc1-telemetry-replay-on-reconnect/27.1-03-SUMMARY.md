# Phase 999.1 Plan 03: Bridge buffer-replay poller — fill gaps from fc1

Bridge container now polls fc1's `/telemetry/since` every 30s with a 15s HTTP timeout, INSERTing buffered points into Timescale at their original DDS timestamps using `ON CONFLICT (topic, time) DO NOTHING`. The live `insertTelemetry` path was refactored to a 4-arg signature `(topic, value, tsMs, tsNs)` so RH/Temperature subscriptions can write the original `msg.header.stamp` (instead of `new Date()`), and every live insert advances the buffer-replay cursor so a post-restart poll doesn't re-fetch the entire 24h buffer. Not yet deployed — Plan 04 / Wave 3 owns the rebuild + UAT.

- **Lesson:** When running parallel to another executor, run `git status` before staging and use `git diff --cached` to inspect the index before `git commit`.
