    Fix CR-02: both `/camera/snapshot` and `/camera/latest.jpg` serve `latestFrame` with no age check. If the camera disconnects but the bridge stays running, the agent will silently post a days-old photo.

    Add a `FRAME_MAX_AGE_MS` constant near the top of the file (near the existing `let latestFrame = null; let lastFrameTime = null;` declarations around line 30):
    ```javascript
    const FRAME_MAX_AGE_MS = 2 * 60 * 60 * 1000; // 2 hours
    ```

    Create a helper function right after:
    ```javascript
    function isFrameStale() {
        return !latestFrame || !lastFrameTime || (Date.now() - lastFrameTime > FRAME_MAX_AGE_MS);
    }
    ```

    Modify the `/camera/snapshot` handler (around line 245) to use the staleness check:
    ```javascript
    app.get('/camera/snapshot', (req, res) => {
        if (isFrameStale()) {
            return res.status(503).json({ error: 'No recent camera frame available' });
        }
        res.writeHead(200, {
            'Content-Type': 'image/jpeg',
            'Content-Length': latestFrame.length,
            'Cache-Control': 'no-cache'
        });
        res.end(latestFrame);
    });
    ```

    Modify the `/camera/latest.jpg` handler (around line 258) identically:
    ```javascript
    app.get('/camera/latest.jpg', (req, res) => {
        if (isFrameStale()) {
            return res.status(503).json({ error: 'No recent camera frame available' });
        }
        res.writeHead(200, {
            'Content-Type': 'image/jpeg',
            'Content-Length': latestFrame.length,
            'Cache-Control': 'no-cache'
        });
        res.end(latestFrame);
    });
    ```

    This ensures both endpoints return 503 when the frame is stale (null, no timestamp, or older than 2 hours). The farmos-agent already handles 503 by falling back to the disk snapshot directory, so this change is safe.
