# v1.7 Learnings Roll-Up

Cross-cutting themes that recur across 2+ phases, and concrete recommendations for v1.8 scoping.

## Headline

v1.7 added the Signal -> extract -> confirm -> farmOS write loop. Five phases shipped on code (38/39/41), one is code-complete pending a real dev-farmOS run (40), one is scaffolded pending real biological time (42). Every blocker remaining is operator-bound or calendar-bound; zero code-quality blockers. The milestone's biggest contribution beyond features is a hardened set of ship-gate process rules.

## Cross-cutting themes

### 1. Real-data ship-gate is non-negotiable -- and it pays off every single time

- **Phase 38:** Closed twice. First close on curated-only PASS retracted same hour when real inoc went 0/4 through the live alerter. Lesson pinned as `feedback_real_data_before_ship_gate_pass`.
- **Phase 39:** Applied prophylactically (`prod-draft-awaiting.json` from real f1 session) before close. No bugs surfaced -- still cheap insurance.
- **Phase 40:** 92 / 92 unit-PASS. Dev-farmOS smoke surfaced 3 legitimate blockers in 7 minutes (fungi_type missing, taxonomy underseeded, error-class confusion). Two fixed live (commit 6b8f1a9); one is operator-owned.

**v1.8 implication:** ship-gate definition for every future phase MUST include "at least one real-prod fixture executed live against the target system, not against mocks." No exceptions, no curated-only exits.

### 2. Smoke before paid batch (and the smoke catches stuff unit tests can't)

- **Phase 38 Plan 09:** $0.51 smoke -> green -> $4.75 full batch -> 95.8% PASS. Without the smoke, the FAIL run 1 ($5.65) would have repeated for every iteration.
- **Phase 40 dev-smoke:** 7-minute synthetic confirmed-draft surfaced 3 integration gaps that 92 unit tests didn't.
- **Phase 41:** `--smoke` flag inherited as first-class harness mode + `EVAL_COST_CAP_USD=20` defensive cap.

**Pattern:** smoke (5-10 fixtures or one synthetic draft) before any expensive / paid / live-side-effecting run.

### 3. Live API shape != mocked unit-test shape

- **Phase 38 Plan 03 -> Plan 07:** Two Anthropic API-shape bugs (inlineTopLevelRef + few-shot tool_result blocks) shipped behind 125/125 green mocked unit tests. Only Plan 07's first live call surfaced HTTP 400.
- **Phase 40 Plan 04 -> dev-smoke:** `fungi_type` missing entirely from JSON:API payload; tests asserted payload-shape but didn't compare against farmOS's actual required-field list.

**v1.8 implication:** every live external system (Anthropic, farmOS, Signal-cli, Whisper) needs a `live-smoke` test in CI / pre-deploy that hits the real API with one canary fixture. Filed as backlog candidate post-v1.7.

### 4. Spec lock != instance state

- **Phase 38 D-08 / D-09 (Plan 08 delta):** B5 regex carried "{SPECIES3}" in the strawman for ~1 year; live production data immediately showed 2-letter codes (DT) on first scan. Corpus context (notebook year) was page-inferred in spec, operator-supplied in reality.
- **Phase 40 dev-smoke:** schema lock at 2026-05-11 specified `species` / `fungi_type` / `substrate_type` taxonomies; dev-farmOS instance at 2026-05-13 had `species` as a 404 and `fungi_type` underseeded.

**v1.8 implication:** taxonomy-seed / data-seed protocols are first-class deliverables for any phase that depends on a downstream instance. Don't trust the spec; probe the instance during phase planning.

### 5. Layered idempotency (state-machine + remote-key) is the right shape

- **Phase 39:** Atomic `UPDATE ... WHERE status='awaiting_farmer' RETURNING id` at state-machine layer; rowCount=0 = idempotent ack.
- **Phase 40:** Local `farmos_response` cache + read-back-first commit; no re-query of remote for dedup. Adds a second layer keyed by `signal_draft.id`.

Each phase closes idempotency at its own seam; the next layer doesn't have to absolutely trust the prior one. Pattern reusable for any chained write path.

### 6. Polling watchdogs > per-row timers for cross-restart safety

- **Phase 39:** Draft pending-timeout watchdog polls every 60s, awaited at boot. Survives alerter restarts (fc-core/alerter restarted 6+ times in the prior week).
- **Phase 40:** commit-watchdog with same shape; stale-lock release via SQL-time-guard prevents stuck `committing` rows.

State lives in Timescale, not in node memory. Pattern: any time-based action -> polling-worker + DB-state, not in-memory setTimeout.

### 7. Compose env passthrough is now muscle memory

- **Phase 36:** hourly false-alarm spam from `ALERT_SHT30_ENABLED` set in `.env` but missing from `docker-compose.override.yml` `environment:` block. Lesson pinned as `feedback_compose_env_passthrough_not_envfile`.
- **Phase 39:** 4 new env vars added to both `config.js` and override.yml in same Plan 02 commit.
- **Phase 40:** all 9 new env vars added to override.yml in same Plan 01 commit as the code change.

Phase 39 and 40 prophylactically applied the Phase 36 lesson. No regressions.

### 8. Paper-trail discipline (every intermediate artifact persisted, named, sibling)

- **Phase 38 Plan 09:** 4 sibling EVAL-REPORT files: `-plan09-smoke.md / -run1-FAIL.md / -run2-PASS.md / .partial.json`. A reader six months from now can `ls` and see lineage.
- **Phase 40 dev-smoke:** v1 + v2 reports captured in `40-DEV-SMOKE-20260513.md` with both the FAIL outcome and the post-fix v2 outcome.
- **Phase 41:** per-run JSONL + per-run Markdown report; `compare-runs.js` regression diff against prior runs.

Memory: `feedback_keep_paper_trail_of_intermediates`. Honored end-to-end.

### 9. Stretch-as-skipped-test is the right shape for operator-deferred work

- **Phase 41:** INGEST-03 audio + INGEST-04 paired-session: wired test files, env-var-honored, marked skipped by default. Operator promotes by supplying corpus; no code change needed. v1.8 path is clean.
- **Phase 40:** 8 integration scenarios skipped pending `FARMOS_INTEGRATION=1`.
- **Phase 42:** entirely scaffolded with re-entry instruction.

Pattern: "human_needed" is a first-class verification status, not a failure mode.

### 10. NORTH-STAR (no farmer bookkeeping tax) survived contact with v1.7

- **Phase 38 D-12:** paper-log batch mode (21 events / 1 page) sends ONE operator-DM summary, not 21 farmer ask-back pings. Explicitly NORTH-STAR-driven.
- **Phase 39:** YES is one tap. Confirmation is the farmer's only ack action.
- **Phase 40:** all writes are farmer-acknowledged (Phase 39 gate); no silent inferred writes.
- **Phase 41:** synthetic + paper-log corpora are validation, not data-entry tax.

Audit confirms PASS at milestone level.

## v1.8 scoping recommendations

### Process changes (locked behaviors)

1. **Ship-gate definition (locked):** every future phase MUST include >=1 live attestation against the real downstream system. No "curated-only PASS" exits. Phase 38 retraction + Phase 40 dev-smoke + Phase 39 prophylactic application are the corpus. (Memory `feedback_real_data_before_ship_gate_pass` already exists; promote to a workflow gate at planning time, not just verification time.)

2. **Smoke-before-paid is the inviolable rule for any cost-domain run** (paid LLM, GPU-hours, batch render, migration, fan-out). Memory `feedback_smoke_before_expensive_batch` already exists; v1.8 phases should pre-declare their smoke fixture set in PLAN.md.

3. **Spec-lock vs instance-state separation in phase planning.** Discuss-phase should produce a "downstream instance probe" checklist before plan-phase. For Phase 40 this would have been "GET /api/taxonomy_term/species before code-complete." Estimated cost: 5 minutes per phase, avoids a dev-smoke FAIL after code-complete.

### Tooling gaps that bit us

4. **Live-API smoke in CI / pre-deploy** for Anthropic + farmOS + Signal-cli + Whisper. Caught Phase 38 Plan 03 shape bugs (twice) and would have caught Phase 40's missing-fungi_type. Estimated $1-3 / run with prompt caching; promote to v1.8 backlog item. (Already filed per v1.7 audit `tech_debt`.)

5. **Taxonomy / data-seed protocol** as a phase deliverable. For Phase 40 this would have been a `40-DEV-FARMOS-SEED.md` runbook executed during dev-bring-up. v1.8 phases that depend on instance-side data should ship a seeding protocol alongside the code.

6. **`fmtNum`-style sanitizer applied at audit-log level**, not just farmer-facing. Phase 40 `latency_ms` uses Math.round; works for now. Consider centralizing through a single helper so style-pin compliance is automatic on every new field.

### Backlog items the data suggests promoting

7. **Phase 36 Plan 04 live attestation** -- cheapest gap to close (30-60 min next session with f1+f2 reachable). Promote immediately.

8. **`farmos_asset_link` install in prod** -- gates the prod-farmOS env-flip + the Phase 42 prod pilot. Coordinate with farm team.

9. **Audio corpus + paired-session peers for INGEST-03/04** -- the only v1.7 phase scope that explicitly defers to v1.8 if unsupplied. Operator action.

10. **999.20 group-thread confirm UX** -- Phase 39 D-06a DMs even for group-originated drafts. Group-mode confirms are a real v1.8 UX question.
