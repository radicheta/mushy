<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Git remote (github.com) → fc1 Pi | fc1/prod branch controls what runs on the Pi. Anyone with push access can modify boot-time behavior. SSH key auth enforced. |
| fc-system-sync ExecStart → /etc | Root-owned oneshot copies files from the repo working tree into /etc. Blast radius = whatever the repo contains. |
| repo on Pi disk → fc-system-sync | If an attacker can modify /home/ubuntu/mushroom_farm_ws/mushy-repo without going through git, they can inject arbitrary /etc/netplan content. Requires ubuntu-level access, which is already the security boundary. |
| wlan0 PSK stored in git | Hashed via wpa_passphrase (not reversible to plaintext for practical attacks). Still grants the holder access to mossrock-lab. Acceptable for project-specific credentials in a private repo. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-04-01 | Tampering | PSK committed to git | accept | Hashed (not plaintext). Private repo. Rotatable by changing MiFi password if compromised. |
| T-09-04-02 | Denial of Service | Bad netplan syntax bricks wifi on next boot | mitigate | Task 3 dry-run validates syntax locally. Task 4 does not apply. fc-system-sync does `netplan generate` only, not `apply`, so a bad config surfaces at generate time, and systemd-networkd falls back to its existing /run state. |
| T-09-04-03 | Denial of Service | mossrock-lab out of range + mossrock-starlink also down = no network | mitigate | Both APs in access-points list; wpa_supplicant will retry indefinitely. Cellular MiFi hardware is stable; starlink is farm-wide. Physical visit required to recover either way, which is the already-accepted SPOF from project_fc1_only_link_weak_wifi.md. |
| T-09-04-04 | Elevation of Privilege | fc-system-sync runs as root early in boot | accept | Narrow ExecStart: only reads two paths from repo, writes two paths in /etc, runs netplan generate + daemon-reload. No shell expansion of user input. Repo path is trusted (same trust boundary as fc-update). |
| T-09-04-05 | Spoofing | Rogue AP with SSID "mossrock-lab" in range | accept | wpa_supplicant associates only if the PSK matches. PSK is non-trivial. Rogue AP without PSK fails association; Pi falls back to mossrock-starlink (open — acceptable because current state is already open on mossrock-starlink). |
| T-09-04-06 | Information Disclosure | SSH session in Task 4 over flaky Tailscale | accept | Tailscale is encrypted end-to-end; no credential exposure. Flakiness is a liveness issue, not a confidentiality issue. |
</threat_model>
