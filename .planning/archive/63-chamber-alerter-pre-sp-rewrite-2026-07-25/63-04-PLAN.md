<interfaces>
Detectors (Node → Python), all take explicit params incl. an `effective`/config object, never
module globals:
  is_rh_oob(humidity, effective) — three-way branch: freshness None → compare; state=='stale' →
    suppress (return False); state in ('fresh','cold') → compare abs(humidity-rh_target)>rh_band.
  is_sensor_error(sensor_health) — level==2 → error; NOT suppressed by warm-up (ALRT-05).
  is_pi_offline(*, ws_connected, ros_connected, now_ms, ws_last_connected_ms,
    ros_disconnected_since_ms, fc1_last_msg_ts, config) — three OR-branches; ws/ros branches use
    config.pi_offline_min*60000; fc1-dark branch uses module constant FC1_DARK_THRESHOLD_MS =
    3*60_000 (NOT config). `is not None` gates, never falsy checks.
  is_humidifier_stuck(*, ...) — offline-blindness gates (Pitfall 5): ws_connected False → suppress;
    humidifier_last_msg_ts None → suppress; stale > (sensor_offline_min or 5)*60000 → suppress; else
    rh_rise < 3.0 math. Python has only None — collapse null/undefined to a single `is None` check
    as a DELIBERATE, documented simplification (audit that all Plan-07 call sites pass explicit values).
  is_sensor_silent(*, ...) — minutes-scale (sensor_offline_min), INDEPENDENT of the seconds-scale
    flap floor (Pitfall 4). Never merge the two thresholds.

Snooze grammar (snooze.js): module-level compiled STRICT + SIMPLE regexes (anchored,
case-insensitive), VALID_DURATIONS map, whitelist of 6 alert types + "all". Analog:
signal_io/router.py `_COMMAND_RE` style. parse_snooze_command(text, now_ms) returns a dict;
unrecognized/malformed → {"ok": False, ...} (mirror router.resolve_farmer "never returns None,
never raises"). Does NOT re-implement keyword detection (router already did that) — receives text
already identified as command-shaped.
