```javascript
const pool = new Pool({
```

**b) Schema init function (per D-08):**
```javascript
async function initDb() {
    try {
        await pool.query(`
            CREATE TABLE IF NOT EXISTS telemetry (
                time   TIMESTAMPTZ      NOT NULL,
                topic  TEXT             NOT NULL,
                value  DOUBLE PRECISION NOT NULL
            )
        `);
        await pool.query(`
            SELECT create_hypertable('telemetry', 'time',
                if_not_exists        => TRUE,
                chunk_time_interval  => INTERVAL '1 day'
            )
        `);
        await pool.query(`
            CREATE INDEX IF NOT EXISTS idx_telemetry_topic_time
            ON telemetry (topic, time DESC)
        `);
        console.log('[db] Schema initialized');
    } catch (err) {
        console.error('[db] Schema init failed:', err.message);
        // Continue anyway — live WS still works without DB
    }
}
```

**c) Set up Express + WebSocket on single port (per Research recommendation):**

```javascript
const http = require('http');
const express = require('express');
const WebSocket = require('ws');

const app = express();
const server = http.createServer(app);
const wss = new WebSocket.Server({ server });
```

**e) Subscribe to all 4 ROS topics (per D-10) with broadcast + DB insert (per D-01, D-03). Use plugin.js key format for the topic column (fc.humidity, fc.temperature, fc.co2, fc.humidifier):**

Topic mapping (ROS topic -> DB topic key -> extract logic):
- `fc1/humidity` (sensor_msgs/msg/RelativeHumidity) -> `fc.humidity` -> `msg.relative_humidity * 100`
- `fc1/temperature` (sensor_msgs/msg/Temperature) -> `fc.temperature` -> `msg.temperature`
- `fc1/co2` (std_msgs/msg/Float32) -> `fc.co2` -> `msg.data`
- `fc1/actuators/humidifier` (std_msgs/msg/Bool) -> `fc.humidifier` -> `msg.data ? 1 : 0`

Each subscription callback:
1. Extracts value using the extract logic above
2. Broadcasts `{ <fieldname>: value, timestamp: Date.now() }` to WebSocket clients (preserve existing broadcast format for humidity and temperature; add co2 and humidifier fields)
3. If `dbReady`, inserts `INSERT INTO telemetry (time, topic, value) VALUES ($1, $2, $3)` with `[new Date(), 'fc.<topic>', value]` wrapped in try/catch — log error on failure but never throw (per D-01 resilience requirement)

**f) WebSocket connection handling (same as current):**
Store clients in a Set, add on connection, remove on close, broadcast function iterates set.

**g) Startup sequence:**

```javascript
rclnodejs.init().then(async () => {

    process.exit(1);
});
```
