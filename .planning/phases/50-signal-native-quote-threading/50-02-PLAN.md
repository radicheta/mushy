Extend `signal.js send()` with the outbound side of the quote-threading mechanism, and persist the Signal-native ms-ts that /v2/send already returns. The quote option is additive and optional; existing callers (~14 across the codebase) keep working unchanged.

Output: send() gains a `quote` parameter; outbound-db.insertOutbound gains a signal_msg_ts column-write; unit tests cover both quote-bearing and quote-absent paths.
