<objective>
Wire the inbound side of quote-threading. Three coupled changes: (1) `receive-loop.js` persists the Signal-native ms-ts of every inbound + any quote target the farmer attached; (2) `confirm-db.js` gains the `findDraftByQuotedMsgTs` resolver that joins `signal_outbound.signal_msg_ts -> related_draft_id -> signal_draft`; (3) `edit-handler.js` routing prefers the quote-resolved draft over the most-recent-active fallback, and emits the numbered ask-back ONLY when fallback finds >1 active drafts AND the inbound carried no quote.

Purpose: this is the bigger plan in the phase because it closes the loop. Quote-first routing eliminates the most-recent-active heuristic ambiguity that surfaced in Phase 45 live-fire (memory `[[project_phase45_followon_edit_no_disambiguation]]`). The numbered ask-back stays as a ~5-line fallback per CONTEXT D-06 (NOT the primary mechanism). Per CONTEXT D-04 algorithm: quote -> actionable draft = route; quote -> terminal draft = polite ack; no quote or orphan quote = existing fallback with optional numbered ask-back.

Output: capture-side persistence + resolver helper + router patch. Hermetic unit tests cover all four QUOT-06 cases (1-active / 1-active+quote / >1-active+quote / >1-active+no-quote) plus the terminal-draft polite-ack case.

findDraftByQuotedMsgTs (confirm-db.js, new):
  async function findDraftByQuotedMsgTs(pool, quoteMsgTs) {
    if (!quoteMsgTs) return null;
    try {
      const r = await pool.query(
        `SELECT d.*
         FROM signal_outbound o
         JOIN signal_draft d ON d.id = o.related_draft_id
         WHERE o.signal_msg_ts = $1
         ORDER BY o.sent_at DESC
         LIMIT 1`,
        [quoteMsgTs]
      );
      return (r.rows && r.rows[0]) || null;
    } catch (_e) {
      return null;
    }
  }
  Export from confirm-db.js. Uses the idx_signal_outbound_msg_ts partial index from Plan 50-01. ORDER BY sent_at DESC guards the unlikely case where two outbounds collided on the same ms-ts (shouldn't happen but the LIMIT 1 keeps the query bounded).

    1. captureRow + parsedReply land.
    2. If captureRow.quote_msg_ts is set:
       a. quotedDraft = await findDraftByQuotedMsgTs(pool, captureRow.quote_msg_ts).
       b. If quotedDraft AND quotedDraft.status in ('awaiting_farmer', 'commit_failed') -> route reply to quotedDraft. Done.
       c. If quotedDraft AND quotedDraft.status in ('committed', 'discarded', 'expired') -> send polite "that one is already closed" ack referencing the draft's farmer_facing_summary or Plan-06 disambiguator shape; do NOT mutate. Done.
       d. If quotedDraft is null (orphan quote) -> fall through to step 3.
    3. activeDrafts = findAwaitingForSender(pool, senderE164).
    4. If activeDrafts.length === 0 -> existing no-active-draft handling (unchanged).
    5. If activeDrafts.length === 1 -> route to that one (unchanged).
    6. If activeDrafts.length > 1 AND captureRow.quote_msg_ts is NOT set -> emit numbered ask-back (one-shot, ~5 LOC; see below); do NOT mutate any draft this turn.
    7. If activeDrafts.length > 1 AND captureRow.quote_msg_ts WAS set but resolved to null -> this is the "orphan quote with multiple actives" case; treat same as case 6 (numbered ask-back) per CONTEXT spirit.
