    1. Parse draft_json. Pull event_date, groups[], notes. Reject (return ok=false, reason='invalid_seeding_session') if groups empty or event_date missing.

RECONCILIATION DECISION (per [[feedback_friction_policy_missing_vs_mismatch]] — silent canonical-source-wins): use fungiTypeName='session' AND, if the term lookup fails (fungi-type-cache returns reason='not_found'), surface a clear ok=false reason='session_fungi_type_term_missing' so the operator knows to create the term once. Plan 05's live-fire validates the term exists in dev farmOS; if not, operator creates it as a one-time prereq. Alternative: pick the first group's species as the session's fungi_type — REJECTED here because it would link the session to one strain when it's multi-strain; flag in SUMMARY for operator decision if 'session' term creation is blocked.
       Actually, simpler resolution: extend assets.js with an optional flag `allowNoFungiType: true` that omits the relationships.fungi_type entry when set; use that for session asset creation. fungiXingName still 'block' (or a new 'session' xing if it exists). PICK the simpler path: extend assets.js to allow omitting fungi_type for session assets. Document the choice in the SUMMARY.
    3. CHILD LOOP: for each group g, for each index i in 0..g.qty.value-1:
         - childName = g.child_block_names.value[i]
         - parentName = g.parent.value (may be 'NO_PARENT' sentinel — see step 3c)
         - SOURCE-BLOCK RESOLUTION: call findAssetByName(client, parentName). If not found AND parentName !== 'NO_PARENT', create the source block via createFungiAsset({name: parentName, fungiTypeName: g.species.value, fungiXingName:'block', draftId}).          - CHILD BLOCK CREATE: createFungiAsset({ name: childName, fungiTypeName: g.species.value, fungiXingName:'block', draftId, parentIds: parentName==='NO_PARENT' ? [sessionAssetId] : [sourceBlockId, sessionAssetId] }). Order matters per Gray Area B: source first, session second.
         - SEEDING LOG CREATE: createLog(client, 'seeding', { name: 'Inoc '+childName, timestamp: epochSecondsForDate(event_date), assetIds:[childBlockId], notes: draft.draft_json.notes || '', draftId }).

DELETE each via assets.deleteFungiAsset(client, id) in REVERSE order (children first, then source blocks, then session). Each DELETE is best-effort; on DELETE failure, auditLogger.logCommit('orphan_cleanup_failed', draft, { orphan_asset_id: id, original_failure_reason: reason }). Note: asset_ids is empty on failure because the caller's view is "nothing committed" — the orphans either got cleaned up or are audit-logged for sweep.
