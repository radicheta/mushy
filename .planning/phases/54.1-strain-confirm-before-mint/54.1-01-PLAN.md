<objective>
Build the shared strain resolver: exact-match an extraction strain code against the
curated 14-code active set (`config.strains`, loaded from `tenants/mossrock/strains.yaml`).
Returns KNOWN vs UNKNOWN. No fuzzy auto-resolve -- an unknown code is held for the farmer,
period. A `nearestKnown` helper computes a single nearest-neighbor suggestion for
DISPLAY ONLY (the ask-back / batched message uses it as "did you mean <X>?"); it never
auto-remaps.

Purpose: This is the single primitive both the backfill path (Plan 02) and the live
capture path (Plan 03) depend on. Centralizing detection here guarantees both paths use
identical match semantics and prevents the dev-farmOS pollution terms (LIM/SHIITAKE/OYS/CAR)
from being silently matched -- because we match the curated source-of-truth list, never
live farmOS terms (CONTEXT decision 1).

Output: `src/farmos/strain-resolver.js` with `resolveStrain` + `nearestKnown`, plus a Jest
test asserting the Cycle-1 variant cases (LIM, SHIITAKE, SHITAKE, OYS, KOY, POY) all
resolve UNKNOWN.
</objective>
