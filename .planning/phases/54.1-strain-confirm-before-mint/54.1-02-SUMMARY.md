## Deviations from Plan

**1. [Design - Simplification] sendUnknownStrainBatch extracted as a testable helper rather than inlined into main()**

The plan specifies wiring the signal send via a factory arg to `main()`. Instead, `sendUnknownStrainBatch` was extracted as a separate exported function (also injectable via its `signalSend` arg). This is strictly simpler to test and matches the plan's intent while avoiding the complexity of driving `main()` through the full page-dispatch pipeline in tests. The `main()` function calls `sendUnknownStrainBatch` after the page loop, fulfilling the plan requirement.

**2. [Design - Remap path] Draft flipped + rewritten in updateDraftStatus before commit**

The plan describes "rewrite the held draft's strain to the canonical code" but doesn't specify exactly when the DB write happens. The implementation writes `draft_json` (with the canonical code) in the same `updateDraftStatus` call that flips to `confirmed`, then fetches the updated draft for commit. This is atomic from the commit-router's perspective and avoids a stale-read race.
