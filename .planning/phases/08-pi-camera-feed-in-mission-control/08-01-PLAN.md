**Node class `FcCamera(Node)`:**
- `__init__`: Call `super().__init__('fc_camera')`
- Declare 6 parameters with defaults: `camera_simulation_mode` (False), `camera_device` (0), `camera_width` (640 per D-05), `camera_height` (480 per D-05), `camera_fps` (1 per D-04), `camera_jpeg_quality` (65 per D-06)

- If simulation mode: set `self.cap = None`, log info

**`capture_and_publish(self)` method:**
- If `self.cap is None or not self.cap.isOpened()`: return (no-op in sim mode or unavailable camera)
- `import cv2` (lazy import to avoid import error when opencv not installed in test)
- `ret, frame = self.cap.read()` -- if not ret, log warning and return

- Create `CompressedImage()`, set `msg.header.stamp`, `msg.format = 'jpeg'`, `msg.data = buf.tobytes()`
- Publish. Wrap in try/except Exception to never crash the node (per fc_sensors.py pattern).

**`destroy_node(self)`:** Release capture if open, call super().

**`main(args=None)`:** Standard rclpy init/spin/shutdown pattern matching fc_sensors.py.
