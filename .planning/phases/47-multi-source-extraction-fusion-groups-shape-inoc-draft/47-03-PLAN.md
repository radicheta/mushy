<objective>
Add the pipeline branch that handles a `seeding_session` draft with `needs_input='starting_seq'`. Two-part work: (1) a pure `seq-helper.js` module that queries the last-SEQ-today from `signal_draft` (and, when available, farmOS) and a pure `mintChildBlockNames(date, species, startSeq, qty)` minter; (2) pipeline wiring that, on a seeding_session ask-back path, builds the farmer-facing prompt with the default-N hint and dispatches `send_starting_seq_askback`; on a subsequent farmer numeric or YES reply, fills `child_block_names` and clears `needs_input`.

Purpose: this is the ask-back closing of the Gray Area 3 lock. Without it, photo-absent sessions stall as `NEEDS_SEQ` drafts forever.

Output: new seq-helper.js + modified pipeline.js + tests covering the helper and the new pipeline branch.
</objective>
