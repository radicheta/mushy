<action>
Create `src/agents/alerter/src/confirm/parser.js`. Top-of-file comment names Phase 39 + D-01 + D-01a. Export:

- `REPLY_KINDS = Object.freeze({ YES: 'YES', NO: 'NO', EDIT: 'EDIT', NOOP: 'NOOP' })`
- `parseReply(body)` -- `(string|null|undefined) -> { kind: 'YES'|'NO'|'EDIT'|'NOOP', editText?: string }`. No throws.

Behavior:
1. Null/undefined/non-string body -> `{kind: 'NOOP'}`.
2. Trim. If empty -> `{kind:'NOOP'}`.
3. If body is pure emoji/symbol/punctuation (no letters, no digits) -> `{kind:'NOOP'}`. Implementation: test the trimmed body against `/^[\p{Emoji}\p{P}\p{S}\s]*$/u` after stripping ASCII letters/digits, OR simpler: if `/[A-Za-z0-9]/.test(trimmed) === false` -> `{kind:'NOOP'}`. The latter is the recommended implementation -- punctuation+emoji bodies are NOOPs by construction.
4. Lowercase the trimmed body. Take first token (split on whitespace). Apply set membership:
   - YES set: `yes`, `y`, `ok`, `si`, `sí` (with accent literally), `sì` (Italian variant -- optional, NOT in D-01; OMIT it for now)
   - NO set: `no`, `n`, `cancel`, `stop`
5. If first token is in YES set -> `{kind:'YES'}`.
6. If first token is in NO set -> `{kind:'NO'}`.
7. If first token equals `edit` -> `{kind:'EDIT', editText: <remainder after the 'edit' token, trimmed, original casing preserved>}`. If remainder is empty, `editText` is the empty string (caller decides whether to ignore or echo back).
8. Otherwise (first token isn't a recognized keyword) -> `{kind:'EDIT', editText: <full original-cased trimmed body>}` (D-01: "first-word other than the YES/NO families -> treat as EDIT with the full reply body as correction text").

The function must NOT call any logger, file system, or network resource. Single export, ~30 lines.
</action>
