<action>
Create `src/agents/alerter/src/confirm/watchdog.js`. Factory `createWatchdog({ pool, confirmDb, outboundConfirm, config, logger = console, clock = { now: () => Date.now() } })`. Returns `{ start, stop, tickOnce }`.

Computed thresholds at construction time:
- `timeoutMin = config.draftPendingTimeoutMin` (default 30)
- `nudgeMin = Math.round(config.draftPendingTimeoutMin * config.draftNudgeFraction)` (default 24 = round(30*0.8))
- `intervalMs = config.draftWatchdogIntervalMs` (default 60000)

`async tickOnce()`:

1. Find nudge candidates: `const nudgeRows = await confirmDb.findNudgeCandidates(pool, nudgeMin);`. For each:
   - Compute minutes-remaining: `Math.max(0, timeoutMin - Math.round(elapsedMin))` where elapsedMin = (now - row.updated_at) / 60000. Wrap row.updated_at parsing defensively.
   - Mark nudge sent first (conditional WHERE in markNudgeSent ensures idempotency across crashes): `const mark = await confirmDb.markNudgeSent(pool, row.id);`. If `mark.rowCount === 0`, skip the send (another tick or process already nudged).
   - If mark.rowCount === 1: dispatch `outboundConfirm.dispatch('send_nudge', row, { minutesRemaining })`. Append event via `confirmDb.appendEventViaPool(pool, row.id, 'nudge_sent', { minutesRemaining })`.
   - Each row in its own try/catch -- one bad row must not stop the tick.
2. Find expire candidates: `const expireRows = await confirmDb.findExpireCandidates(pool, timeoutMin);`. For each:
   - `const exp = await confirmDb.expireDraft(pool, row.id, 'timeout_expired');`. The conditional WHERE clause inside expireDraft makes this idempotent.
   - If `exp.rowCount === 1` (we actually transitioned the row): dispatch `outboundConfirm.dispatch('send_expired_note', row)`. (expireDraft already appended an 'expired' event row internally; do NOT append another.)
3. Catch any tick-level error, log warn, do not rethrow.

`start()`:
- Call `tickOnce()` immediately, awaited (so the first tick completes before the interval timer is registered -- D-04d). Wrap in try/catch.
- Register `timer = setInterval(() => { tickOnce().catch(e => logger.warn(...)); }, intervalMs);`
- Log info `[watchdog] started: timeout=${timeoutMin}min nudge=${nudgeMin}min interval=${intervalMs}ms`.

`stop()`:
- `if (timer) { clearInterval(timer); timer = null; }`
- Log info `[watchdog] stopped`.

180-line ceiling.

```js
// Phase 39 confirm-reply branch (between snooze and capture).
// Skip when wiring is incomplete (defensive).
if (pool && confirmDb && confirmParser && confirmStateMachine && confirmOutbound && editHandler && text) {
  let draftRow = null;
  try {
    draftRow = await confirmDb.findAwaitingForSender(pool, source);
  } catch (e) {
    logger.warn(`[receive] confirm lookup failed: ${e.message}`);
  }
  if (draftRow) {
    const parsed = confirmParser.parseReply(text);
    if (parsed.kind === 'YES') {
      const r = await confirmDb.confirmDraft(pool, draftRow.id);
      if (r.ok && r.rowCount === 1) {
        await confirmOutbound.dispatch('send_confirm_ack', draftRow);
      } else if (r.ok && r.rowCount === 0) {
        await confirmOutbound.dispatch('send_confirm_idempotent_ack', draftRow);
      } else {
        logger.warn(`[receive] confirm error: ${r.reason}`);
      }
      continue;
    }
    if (parsed.kind === 'NO') {
      const r = await confirmDb.discardDraft(pool, draftRow.id);
      if (r.ok && r.rowCount === 1) {
        await confirmOutbound.dispatch('send_discard_ack', draftRow);
      }
      continue;
    }
    if (parsed.kind === 'EDIT') {
      const editText = parsed.editText || '';
      const eh = await editHandler.handleEdit(draftRow, editText);
      if (eh.ok && eh.sideEffect === 'send_edit_cap_msg') {
        // Cap exceeded: transition the draft + send cap message.
        await confirmDb.expireDraft(pool, draftRow.id, 'edit_cap_exceeded');
        await confirmOutbound.dispatch('send_edit_cap_msg', draftRow, { maxEditTurns: config.maxEditTurns });
      } else if (eh.ok && eh.sideEffect === 'send_preview_resend') {
        await confirmOutbound.dispatch('send_preview_resend', draftRow, { newPreview: eh.newPreview });
      } else if (eh.ok && eh.sideEffect === 'noop') {
        // Draft was no longer active when the UPDATE landed (concurrent confirm/expire). Silent.
        logger.info(`[receive] edit noop: ${eh.reason}`);
      } else {
        logger.warn(`[receive] edit failed: ${eh.reason}`);
      }
      continue;
    }
    // parsed.kind === 'NOOP': fall through to capture pipeline (the sticker / empty / pure-emoji case).
  }
}
```
