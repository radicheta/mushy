into the FSM (state.py) which calls detectors (rules.py) and, on a firing transition, formats

integration seam that makes CHM-01 real end-to-end.

composed INTO the existing dispatch, never a second loop. boot.py also finally wires the rate-cap
hook (Pitfall 9) from ChamberConfig. SC1 (bridge disconnect → pi-offline alert within timeout) is
proven here.

async def test_bridge_disconnect_fires_pi_alert(svc):
    """SC1: fc1 goes dark -> the farmer is told the chamber is uncontrolled.

    Uses the fc1-dark path (the Phase 46 signal): a health poll reports an fc1
    timestamp older than the hardcoded 3-minute threshold, on the pi_liveness
    call site that fast-fires.
    """
    s, client = svc(ALERT_PI_OFFLINE_MIN="5")
    s.state = state.initial_state(BOOT)
    now = BOOT + 90 * MIN                       # past the 60s startup grace

    await s.on_event(
        {
            "type": "pi_liveness",
            "ws_connected": True,
            "ros_connected": True,
            "fc1_last_msg_ts": now - 4 * MIN,   # dark for 4 min > 3 min threshold
        },
        now_ms=now,
    )

    assert s.state.per_type["pi"].state == "FIRING"
    assert len(client.sent) == 1
    assert "FC-1" in client.sent[0]
    assert "chamber uncontrolled" in client.sent[0]


async def test_no_alert_while_healthy(svc):
    s, client = svc()

    now = BOOT + 90 * MIN

    await s.on_event(
        {"type": "pi_liveness", "ws_connected": True, "ros_connected": True,
         "fc1_last_msg_ts": now - 10_000},
        now_ms=now,
    )
    assert client.sent == []


async def test_recovery_is_sent_after_the_alert(svc):
    """The farmer who got the PROBLEM must get the RECOVERY."""

            "source": source,

- **Module docstring** naming the Node files composed (`index.js` wiring, `state.js` FSM,

- `class ChamberService`:
  - `__init__(self, *, config, signal_client, http, log=None, clock=None)` — stores all;
    `self.state = state.initial_state(clock())`. It must NOT construct a `SignalClient`, an
    `httpx.AsyncClient`, or a `ReceiveLoop`. `http` is passed through to `WsClient` in `start()`.
  - `handle_event(event, now_ms=None)` → `state.transition(self.state, event, now, config)`;
    store the new state; return the actions. Pure with respect to I/O.
  - `perform(actions)` → for each action **sequentially** (never `asyncio.gather` — ordering is
    attribution-critical), `await self._signal_client.send(action["body"])`, each wrapped in
    its own try/except that logs and continues. A Signal outage must never propagate into the
    ws loop or roll back FSM state.
  - `on_event(event, now_ms=None)` → `perform(handle_event(...))`.
  - `apply_snooze(parsed)` → build a `snooze` event from `parsed["alert_type"]` /
    `parsed["until_ms"]` and run it through `handle_event`. Do not mutate `per_type` directly —
    routing it through the FSM keeps one code path.
  - `get_summary()` → `{rh, temp, co2, humidifier, humidifier_cycles, pi_last_seen_sec}` read off
    `self.state`, matching `message.format_heartbeat`'s expected keys (Plan 05).
  - `start()` / `stop()` → mirror `receive_loop.py:110-143`. `start` creates two tasks: the
    `WsClient.run()` reconnect loop (with `on_message=` feeding `on_event` and `on_liveness=`
    feeding a `pi_liveness` event) and `heartbeat.heartbeat_loop(...)` with
    `get_summary=self.get_summary` and `dispatch=` a callback that runs the `heartbeat_tick`
    event through `on_event`. `stop` cancels both with the
    `.cancel()` / `await` / `except asyncio.CancelledError: pass` shape.
  - Also create a periodic `tick` event task (Node's eval tick) so the FSM re-evaluates during
    prolonged silence — without it, `sht30`/`scd41`/`pi` can never reach FIRING when no events
    arrive at all. Cancel it in `stop` like the others.
- `make_composite_dispatch(*, chamber_service, pipeline_handle, signal_client, config, log=None)`
  returning an async `dispatch(env)`:
  ```
  text = <read the DM body via router.classify_envelope(env)>   # tolerate junk -> ""
  parsed = snooze.parse_snooze_command(text, now_ms=<clock>)
  if parsed["ok"]:
      chamber_service.apply_snooze(parsed)
      if parsed.get("ack_text"):
          await signal_client.send(parsed["ack_text"])
      return                                   # do NOT fan out
  if parsed.get("reply"):
      await signal_client.send(parsed["reply"])   # snooze-shaped but malformed: help text
      return
  await pipeline_handle(env)                   # everything else is farmer speech
  ```
  It performs NO whitelist check — that already happened in `ReceiveLoop.tick` (V4). Adding one
  here would be harmless; adding an ingestion path that skips it would be the bug.
