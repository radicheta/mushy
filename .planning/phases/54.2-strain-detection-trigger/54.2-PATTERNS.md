**Note the signature gap:** this dispatcher is `dispatch(sideEffect, draftRow)` — TWO args,

just sanitizes+sends `farmer_facing_preview`, outbound.js:77-90). Option (b) reuses
`sendAskBack` unchanged and keeps the extras out of this dispatcher — likely the smaller diff,

### `src/farmos/fungi-type-cache.js` — existence-check contract (READ-ONLY; utility)

**No edit.** This is the contract the gate consumes. **Gate ONLY on `fungi_type_not_found`**
(Decision 2). Discriminated return, fungi-type-cache.js:35-51:
```js
async function getFungiTypeUuid(client, typeName) {
  const cached = _get(typeName);
  if (cached) return { ok: true, uuid: cached, cached: true };
  const enc = encodeURIComponent(typeName);
  const r = await client.get(`/api/taxonomy_term/fungi_type?filter[name][value]=${enc}`);
  if (!r.ok) {
    if (r.status === 404) return { ok: false, reason: 'fungi_type_taxonomy_missing' };
    return { ok: false, reason: 'http_' + (r.status || 'network') };
  }
  const arr = r.body && r.body.data;
  if (!Array.isArray(arr) || arr.length === 0) {
    return { ok: false, reason: 'fungi_type_not_found', typeName };  // <- THE ONLY actionable case
  }
  const uuid = arr[0].id;
  _set(typeName, uuid);
  return { ok: true, uuid };
}
```

| Return | Gate action |
|--------|-------------|
| `{ ok:true, uuid, cached? }` | Known — do NOT ask |
| `{ ok:false, reason:'fungi_type_not_found', typeName }` | **Collect as unknown -> ask the farmer** |
| `{ ok:false, reason:'fungi_type_taxonomy_missing' }` (HTTP 404) | Pass through — do NOT ask (infra) |
| `{ ok:false, reason:'http_<status>' / 'http_network' }` | Pass through — do NOT ask (infra) |

**The "only honest not-found is actionable" rule to mirror** — `ensureFungiTypeUuid`, fungi-type-cache.js:62-64:

### "Only honest not-found is actionable" (infra vs. actionable discrimination)
**Source:** `src/farmos/fungi-type-cache.js:62-64` (`ensureFungiTypeUuid`)
**Apply to:** the per-code detection loop. Treat ONLY `reason==='fungi_type_not_found'` as
"ask the farmer"; every other `ok:false` (and `ok:true`) passes through. Prevents asking
during a farmOS outage (Decision 2 / Pitfall 1).
