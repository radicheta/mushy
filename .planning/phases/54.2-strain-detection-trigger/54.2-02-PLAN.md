<objective>
Build the missing detection trigger: walk a fresh draft's strain codes, check each
against farmOS, and if any are cleanly not-found, hold the draft and emit ONE batched
ask-back — pre-empting the commit that would otherwise fail. This is the live wiring of
the 54.1 back-half (render/parse/dispatch/mint already shipped).

The gate is factored into a shared helper `maybeHoldForStrainConfirm` called after the
starting_seq short-circuit so a session needing both resolves SEQ first (R1). Multi-group
corrections are scoped to single-code with an explicit LOGGED limitation (R2 option b) —
never a silent no-op.

Purpose: Close the detection gap explicitly deferred in 54.1-03. The 2026-05-30 PB2
session was confirmed YES then commit_failed x3 because nothing asked "is PB2 a new
strain?" before commit.
Output: A live capture path that holds unknown-strain drafts and asks the farmer;
unit + integration + R2 tests; STRAIN-07 recorded as dissolved-by-design.

STRAIN-07 is satisfied as dissolved-by-design: a farmer-confirmed code becomes a farmOS
fungi_type term via the already-wired ensureFungiTypeUuid{create:true} on YES, so the NEXT
capture's getFungiTypeUuid finds it. NO new persistence store is built (CONTEXT Decision 1).
</objective>
