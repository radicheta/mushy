Create `.planning/phases/40-farmos-write-path/40-RUNBOOK.md`. Sections:

1. **Pre-flight check** -- before running the live UAT:
   - Dev-farmOS reachable at http://10.68.155.50:18080
   - Alerter container has FARMOS_USERNAME + FARMOS_PASSWORD set
   - `docker compose logs alerter | grep '\[farmos\] asset_link module'` shows the probe result
   - `docker compose logs alerter | grep '\[commit-watchdog\] started'` confirms the watchdog is running

2. **Live-farmer UAT script** (mirror Phase 39 structure):
   - Farmer sends a Signal voice note describing an inoc session with photo
   - Operator watches `docker compose logs -f alerter | jq 'select(.event)'`
   - Expected sequence: capture_inserted -> extract_complete -> preview_sent -> [farmer YES] -> confirm_ack -> commit_attempt -> commit_success
   - Verify in dev-farmOS UI: new BATCH-*, new block asset, seeding log

3. **Audit recipe (D-06a):**
```sql
SELECT id, farmos_person, log_type, farmos_response, committed_at
  FROM signal_draft
 WHERE status = 'committed'
   AND committed_at > NOW() - INTERVAL '24 hours'
 ORDER BY committed_at DESC;
```
   Or for full event trail of a specific draft:
```sql
SELECT created_at, event, details
  FROM signal_draft_event
 WHERE draft_id = '<id>'
 ORDER BY created_at;
```

4. **Recovery procedures (D-07b):**
   - **commit_failed recovery:** `UPDATE signal_draft SET status='confirmed', commit_attempt_count=0, commit_failed_reason=NULL WHERE id='...';`
   - **Stuck committing row recovery:** Auto-released after COMMIT_LOCK_STALE_MIN minutes. Force release: `UPDATE signal_draft SET status='confirmed', committed_at_attempt=NULL WHERE id='...';`
   - **farmOS-side asset went away (rare):** delete signal_draft row, re-ingest the original Signal capture (Phase 38 will produce a fresh draft).

5. **Dev -> prod env-flip:**
   - Pre-condition: farm team has installed `farmos_asset_link` module in prod (per the 2026-05-11 lock note).
   - Operator updates `.env`: `FARMOS_URL=http://10.68.155.50:8082` (or whatever the prod host:port is).
   - Restart alerter: `docker compose up -d --build alerter`.
   - First log line confirms: `[farmos] asset_link module: present`.

6. **Backoff + retry observability:** describe how to interpret `commit_attempt_retry` events; how to spot a stuck retry loop (attempt_count near retryMax across many drafts).

7. **Known limits / deferred items:**
   - No prod-farmOS writes (env-flip gated on module install)
   - Custom bundles not supported (C5 forbids; native types only)
   - Single-draft-at-a-time commit; bulk paper-log mode routes to needs_review per Phase 38 D-12

No em-dashes; use `--` or rephrase. Farmer-facing numbers (none expected here, but if any appear) use fmtNum.
