<title>qr.js -- resolve + bind paths (module + fallback)</title>
<read_first>
- .planning/phases/40-farmos-write-path/40-RESEARCH.md section 4
- .planning/phases/40-farmos-write-path/40-CONTEXT.md D-04, D-04a

<action>
Create `src/agents/alerter/src/farmos/qr.js`. Three exports:

1. `async resolveQr(client, qrCode)`:
   - `const present = await client.probeAssetLinkModule();`
   - If present: `GET /api/asset_link/farmos_asset_link?filter[qr_code]=<encodeURIComponent(qrCode)>`. Parse `data[0].relationships.asset.data.id` if present.
   - If absent (fallback): `GET /api/asset/fungi?filter[farm_id_tag.qr_code][value]=<encoded>`. Parse `data[0].id` if present.
   - Return `{found, assetId, path: 'asset_link'|'farm_id_tag'}` on success, `{found:false, error}` on transport error.

2. `bindQrOnCreate(assetPayload, qrCodes)`:
   - When called for the fallback path (caller checks `client.probeAssetLinkModule()` returned false), mutate the payload by adding:
     ```
     attributes.farm_id_tag = qrCodes.map(c => ({qr_code: c}))
     ```
   - When module is present, this is a NO-OP (binding goes through bindQrPostCreate). The caller is responsible for choosing the correct path, so this function only adds the field when an opts flag instructs it to (signature: `bindQrOnCreate(payload, qrCodes, {fallback:true})`).

3. `async bindQrPostCreate(client, assetId, qrCodes)`:
   - For module-present path. For each qrCode: POST /api/asset_link/farmos_asset_link with the body shown in RESEARCH section 4.
   - Returns `{ok, bindings:[{qr_code, link_id, ...}]}`. Any individual failure is logged and recorded in bindings; method does not throw.

Header lists Phase 40 + D-04 + D-04a + no-em-dash rule.
</action>
<acceptance_criteria>
- resolveQr returns the right assetId on the asset_link path when probe says present
- resolveQr falls back to the fungi filter when probe says absent
- bindQrOnCreate mutates the payload when {fallback:true}; leaves untouched otherwise
- bindQrPostCreate posts N times for N qrCodes
- A bindQrPostCreate failure on one code does not abort the others
</acceptance_criteria>
</task>

<read_first>
- .planning/phases/40-farmos-write-path/40-RESEARCH.md section 5

<action>
Create `src/agents/alerter/src/farmos/files.js`. Single export `uploadAttachment(client, absPath, filename)`:

1. `await fs.promises.access(absPath, fs.constants.R_OK)` -- if it throws, return `{ok:false, reason:'attachment_missing', skipped:true, path:absPath}` and log WARN one line.
2. `const bytes = await fs.promises.readFile(absPath);` -- no encoding, no thumbnailing (D-05b).
3. `const r = await client.postBinary('/api/file/file', bytes, {filename: filename || path.basename(absPath), timeoutMs: 30000});`
4. On `r.ok` extract `r.body.data.id` -> return `{ok:true, fileId}`.
5. On `!r.ok` return `{ok:false, reason: r.status === ? 'http_' + r.status : 'upload_failed', http_status: r.status}`.

Helper `uploadAttachments(client, paths[])` -- map paths through uploadAttachment, return `{fileIds[], skipped[], failed[]}`. Continues past skipped/failed entries; only `fileIds` are linked into the log.
</action>
<acceptance_criteria>
- Missing file resolves to skipped (not an error) -- D-05a respected
- Successful upload returns fileId
- uploadAttachments aggregates partial results without throwing
- 30s timeout passed through to postBinary
</acceptance_criteria>
</task>

<read_first>

<action>
Create `src/agents/alerter/src/farmos/assets.js`. Exports:

1. `async createFungiAsset(client, opts)` where opts = `{name, parentIds=[], speciesUuid=null, draftId, qrCodes=[], notes=null}`:
   - Build payload:
     ```
     { data: { type: 'asset--fungi',
               attributes: { name, status: 'active',
                             notes: { value: (notes ? notes + '\n' : '') + 'mushy:draft:' + draftId,
                                      format: 'plain_text' } },
               relationships: {} } }
     ```
   - If parentIds.length: `relationships.parent = { data: parentIds.map(id => ({type:'asset--fungi', id})) }`
   - If speciesUuid: `relationships.species = { data: [{type:'taxonomy_term--species', id:speciesUuid}] }`
   - Determine module presence: `const present = await client.probeAssetLinkModule();`
   - If !present and qrCodes.length: `bindQrOnCreate(payload, qrCodes, {fallback:true})` (mutates).
   - POST `/api/asset/fungi`.
   - Extract assetId = response.body.data.id.
   - If present and qrCodes.length: `await bindQrPostCreate(client, assetId, qrCodes);`
   - Return `{ok:true, assetId, qrBindings}` or `{ok:false, reason, http_status}` on failure.

2. `async findAssetByName(client, name)` -- helper for BATCH-* parent resolution:
   - `GET /api/asset/fungi?filter[name][value]=<encoded>`
   - Returns `{found, assetId}` or `{found:false}`.
   - Per-process LRU cache (size 32, keyed by name) on the module level.

3. `async resolveOrCreateAsset(client, opts)` -- BATCH-* idiom:
   - Try findAssetByName first; if found, return its id.
   - Otherwise createFungiAsset and return.
</action>
