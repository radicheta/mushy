## Code fixes landed during this cutover

- `qr.js`: replaced `farm_id_tag` attribute name with `id_tag`; removed
  the `farmos_asset_link` PWA-frontend dispatch (always-404 by
  architecture); single resolution path via `id_tag.id` filter.
- `assets.js`: dropped the `probeAssetLinkModule` call + post-create
  asset_link bind path; single POST per asset.
- `client.js`: removed `probeAssetLinkModule` + `_assetLinkPresent`
  tri-state (probe was structurally guaranteed to 404).
- `id_tag.type`: set to `'other'` (not `'qr'`) because prod-farmOS's
  `farm_id_tag` module only allows a restricted set of types. `qr`
  isn't in it; `other` is. If farmOS adds `qr` to the allowed list
  later, flip the constant in `qr.js` line ~15.
- Code commit: `f5b9ad7`.

## Known limitations + side findings

   answer is `'qr'` (or a new dedicated type). farmOS prod's
   `farm_id_tag` module config doesn't include `qr`. Flagged as
   non-blocking; flip a one-line constant in `qr.js` once available.

2. **Legacy `Sawdust` (title-case) term in `substrate_type`** is still
   present from a pre-existing hand-add. Harmless under the C lock
   (substrate is log-only and alerter doesn't read substrate_type
   terms in v1.7).

3. **Retry classifier still treats deterministic failures as
   retryable** (carryover finding from dev smoke). Filed as future
   optimization.
