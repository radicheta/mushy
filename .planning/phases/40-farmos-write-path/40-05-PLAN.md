<action>
Create `src/agents/alerter/src/farmos/commit-watchdog.js`. Factory `createCommitWatchdog({pool, commitDb, farmosClient, commitRouter, ctx, config, auditLogger, logger=console, clock={now:()=>Date.now()}})`.

Constants computed at construction:
- `intervalMs = config.commitWatchdogIntervalMs`
- `batchCap = config.commitWatchdogBatchCap`
- `retryMax = config.commitRetryMax`
- `backoffMs = config.commitRetryBackoffMs`    // array
- `staleMin = config.commitLockStaleMin`

`async _processRow(row)`:
1. **Idempotency probe** (D-02a):
   - `const cache = await commitDb.getCachedResponse(pool, row.id);`
   - If cache.status === 'committed' && cache.farmos_response: log `commit_idempotent_noop` and return.
2. **Acquire lock:**
   - `const lock = await commitDb.acquireCommitLock(pool, row.id);`
   - If lock.rowCount === 0: another worker won this tick; return silently.
   - `const lockedRow = lock.row;`
3. **Backoff gate:** if `lockedRow.commit_attempt_count > 1`:
   - Look up previous attempt timestamp. If `clock.now() - committed_at_attempt < backoffMs[Math.min(lockedRow.commit_attempt_count - 2, backoffMs.length - 1)]`, requeue (don't commit yet) and return.
   - (Simpler alternative: encode the cutoff in the SQL query in findConfirmedCandidates -- but we want to keep candidate query simple; in-JS check is clearer.)
4. **Audit attempt event:** `await auditLogger.logCommit('commit_attempt', lockedRow, {attempt: lockedRow.commit_attempt_count});`
5. **Commit:** `const result = await commitRouter.commit(farmosClient, lockedRow, ctx);`
6. **Branch on outcome:**
   - If result.ok:
     - `await commitDb.markCommitted(pool, lockedRow.id, {asset_ids, log_ids, file_ids, http_status, latency_ms});`
     - `await auditLogger.logCommit('commit_success', lockedRow, result);`
   - Else if isTransient(result) && lockedRow.commit_attempt_count < retryMax:
     - `await commitDb.requeueForRetry(pool, lockedRow.id);`
     - `await auditLogger.logCommit('commit_attempt_retry', lockedRow, {...result, attempt: lockedRow.commit_attempt_count});`
   - Else:
     - `await commitDb.markFailed(pool, lockedRow.id, result.reason || 'unknown');`
     - `await auditLogger.logCommit('commit_failed', lockedRow, result);`

`isTransient(result)` predicate: result.http_status is null/undefined (network error) OR result.http_status >= 500 OR result.reason matches /timeout|abort|econnreset/i.

`async tickOnce()`:
1. `const released = await commitDb.releaseStaleLocks(pool, staleMin);`
2. If released.rows.length: emit `commit_stale_released` audit per id.
3. `const rows = await commitDb.findConfirmedCandidates(pool, batchCap);`
4. For each row: try { await _processRow(row); } catch (e) { logger.warn('[commit-watchdog] row ' + row.id + ' threw: ' + e.message); }

`start()` / `stop()` mirror Phase 39 watchdog (first tick awaited before setInterval registration; log info on start with the configured params).
</action>
<acceptance_criteria>
- start() awaits first tickOnce before registering setInterval
- Idempotency probe short-circuits BEFORE acquiring lock for already-committed rows
- Race-lost acquireCommitLock (rowCount=0) silently returns
- Transient failures route to requeueForRetry when attempts < retryMax
- Transient failures route to markFailed when attempts >= retryMax
- Stale lock release emits one audit event per released row
- Each row wrapped in its own try/catch
- File <= 200 lines
</acceptance_criteria>
