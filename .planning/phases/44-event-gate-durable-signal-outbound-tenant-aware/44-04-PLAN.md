D-02 gate decision flow (mandatory order):
  1. rulePositive(envCtx) hit → return {gate:'fast_event', allow_extract:true, allow_convo:true}
  2. ruleNegative(envCtx, lastBotOutbound, nowMs) hit → return {gate:'skipped_rule_neg', allow_extract:false, allow_convo:false}
  3. else → await haikuClassifier.classify(envCtx)
       - on error/timeout → {gate:'forced', allow_extract:true, allow_convo:true}  (D-03 fail-OPEN)
       - else if r.is_event === true OR r.confidence < 0.7 → {gate:'haiku_event', allow_extract:true, allow_convo:true}
       - else → {gate:'haiku_chitchat', allow_extract:false, allow_convo:false}
