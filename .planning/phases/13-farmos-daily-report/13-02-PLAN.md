    **farmos_agent_node.py** — ROS2 lifecycle node per D-08 and D-11:

    ```python
    class FarmOSAgent(LifecycleNode):
        def __init__(self):
            super().__init__('farmos_agent')
            self._scheduler = None
            self._db_conn = None
            self._session = None
            self._asset_uuid = None
    ```

    Lifecycle callbacks:
    - `on_configure(state)`:
      1. Read env vars: `FARMOS_URL` (default `http://10.68.155.50:8082`), `FARMOS_USERNAME`, `FARMOS_PASSWORD`, `TIMESCALE_HOST` (default `localhost`), `TIMESCALE_PASSWORD`, `REPORT_TIMEZONE` (default `America/Toronto`)
      2. Open psycopg2 connection to TimescaleDB: `host=TIMESCALE_HOST, port=5432, dbname=postgres, user=postgres, password=TIMESCALE_PASSWORD`
      3. Authenticate to FarmOS via `get_session()`
      4. Look up FC-1 UUID via `get_asset_uuid()` and cache in `self._asset_uuid`
      5. Log success. Return `TransitionCallbackReturn.SUCCESS` (or FAILURE on exception)

    - `on_activate(state)`:
      1. Create `BackgroundScheduler()`
      2. Add job with `CronTrigger(hour=6, minute=0)` calling `self.execute_report`
      3. Start scheduler
      4. Log: `[farmos_agent] activated — daily report scheduled at 06:00`
      5. Return SUCCESS

    - `on_deactivate(state)`:
      1. Shut down scheduler if running
      2. Close DB connection
      3. Return SUCCESS

    - `execute_report()` — The observe-synthesize-record loop per D-11:
      1. Compute yesterday's date: `(datetime.now(ZoneInfo(self._tz)) - timedelta(days=1)).date()`
      2. Format date_str: `report_date.strftime('%Y-%m-%d')`
      3. Check for duplicate: `observation_exists_for_date(session, farmos_url, date_str)`. If exists, log skip and return.
      4. **Observe:** Query TimescaleDB via `query_daily_summary(self._db_conn, report_date, self._tz)`
      5. **Observe:** Fetch camera snapshot from bridge: `requests.get('http://localhost:8081/camera/latest.jpg', timeout=10)`. If 503 or error, fall back to reading latest JPEG from `/data/snapshots/fc1/{date_str}/` directory (mounted volume). Log which source was used.
      6. **Synthesize:** Build markdown via `build_report_markdown(summary, config_targets)`
      7. **Record:** Upload photo via `upload_photo(session, farmos_url, jpeg_bytes, f'fc1-{date_str}.jpg')`
      8. **Record:** Create observation via `create_observation(session, farmos_url, self._asset_uuid, f'FC-1 Daily Report {date_str}', markdown_notes, file_id)`. Log name MUST follow the pattern `FC-1 Daily Report YYYY-MM-DD` for idempotency per D-09.
      9. Log success with observation UUID

    Re-auth handling: Wrap FarmOS calls in try/except. If `requests.HTTPError` with status 401, call `get_session()` again, update `self._session`, retry once.

    `main()` function:
    ```python
    def main():
        rclpy.init()
        node = FarmOSAgent()
        # Self-transition since no external lifecycle manager
        node.trigger_configure()
        node.trigger_activate()
        try:
            rclpy.spin(node)
        except KeyboardInterrupt:
            pass
        finally:
            node.destroy_node()
            rclpy.shutdown()
    ```

    If `trigger_configure`/`trigger_activate` are not available in rclpy Jazzy (research assumption A2), fall back to calling `on_configure(None)` and `on_activate(None)` directly in main.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| farmos_agent container -> FarmOS API | Session-cookie auth over HTTP to localhost:8082 |
| farmos_agent container -> TimescaleDB | psycopg2 with password from .env to localhost:5432 |
| farmos_agent container -> Bridge | HTTP GET to localhost:8081 (unauthenticated, internal) |
| .env file -> container environment | Credentials injected via compose env_file |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-06 | Information Disclosure | .env file | mitigate | .env is gitignored; FARMOS_USERNAME/PASSWORD never appear in Dockerfile, source code, or logs. Logger uses `self.get_logger().info()` for status — never log credential values. |
| T-13-07 | Denial of Service | farmos_agent_node.py | mitigate | All HTTP calls have explicit timeouts (10s reads, 30s photo upload). DB connection has connect_timeout=10. execute_report wrapped in try/except — failure logged but does not crash the node. |
| T-13-08 | Repudiation | execute_report | accept | Report is a best-effort daily digest. If it fails, next day's run will succeed. No audit trail beyond FarmOS logs and container logs. Acceptable for a passive reporting agent. |
| T-13-09 | Elevation of Privilege | farmos_agent container | mitigate | Container runs as non-root user (default in ros:jazzy-ros-core). FarmOS credentials grant write to logs only — cannot modify assets, users, or farm configuration. |
</threat_model>
