<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| farmer Signal reply -> confirm_repo | Untrusted farmer input (sender_e164, reply text) crosses into DB writes |
| concurrent watchdog ticks -> signal_draft row | Two coroutines (or two processes during deploy) race on the same row |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-61-01 | Tampering | confirm_draft double-commit | mitigate | SQL `WHERE id=%s AND status='awaiting_farmer' RETURNING id`; rowcount 0 on second YES blocks a second commit-trigger (SC-2) |
| T-61-02 | Tampering | mark_nudge_sent duplicate nudge | mitigate | SQL `WHERE nudge_sent_at IS NULL RETURNING id`; concurrent test asserts exactly one rowcount==1 (SC-3) |
| T-61-03 | Spoofing | farmer B replies to farmer A draft | mitigate | find_awaiting_for_sender scopes the lookup by sender_e164 (ORDER BY updated_at DESC LIMIT 1) |
| T-61-04 | Information Disclosure | e164 phone in logs | mitigate | mask_number() applied to any sender_e164 logged in confirm_repo |
| T-61-05 | Denial of Service | DB error crashes caller | mitigate | never-throws: every public fn returns {ok:False,reason} / [] / None; never raises |
| T-61-SC | Tampering | uv package installs | accept | no new packages added this plan; psycopg3/pytest already vendored (RESEARCH Environment Availability) |
</threat_model>
