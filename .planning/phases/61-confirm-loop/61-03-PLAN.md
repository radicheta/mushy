<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| farmer strain reply -> dispatch | Untrusted strain code/text routed into a confirm or a draft_json species_code rewrite |
| watchdog tick -> signal send + DB | Scheduled side effects (nudge/expire) fire against farmer-facing Signal + DB rows |
| confirm path -> Phase 62 commit-trigger | Marker that authorizes a downstream farmOS write (Phase 62) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-61-09 | Tampering | unknown strain auto-remapped to a curated code | mitigate | exact-match only; nearest_known is display-only; unknown codes always route to farmer ask-back (RESEARCH Pitfall 7; the POY-as-KOY bug) |
| T-61-10 | Repudiation | farmer YES recorded but no ack (silent failure) | mitigate | every terminal post-YES state attempts a farmer ack; ack failure logs WARNING (no-silent-failure rule; relaxed for f1=Santi but ack still fires) |
| T-61-11 | Denial of Service | a watchdog tick error kills the loop | mitigate | never-throws tick wrapper: except Exception -> WARNING + continue; except CancelledError -> raise (clean shutdown only) |
| T-61-12 | Tampering | double commit-trigger from dup YES | mitigate | commit-trigger marker emitted only when confirm_draft rowcount==1; rowcount==0 sends idempotent ack with NO marker |
| T-61-13 | Information Disclosure | e164 in watchdog/dispatch logs | mitigate | mask_number() for any sender_e164 logged |
| T-61-SC | Tampering | uv package installs | accept | no new packages this plan; asyncio stdlib + already-vendored deps (no external Levenshtein lib -- ported verbatim per RESEARCH Don't Hand-Roll) |
