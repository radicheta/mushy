## Document Layout Contract

### OPERATIONS.md (Developer Reference)

Structure — use this exact section order:

1. **Overview** — one paragraph: what the system does, hardware components (Pi 4, SHT30, SSR-10A, GPIO pins)
2. **Architecture** — brief diagram or ASCII: FC-1 Pi → fc-core.service → SHT30 (read) + SSR-10A (write) → OpenMCT dashboard
3. **Configuration** — table of all fc_config.yaml parameters with current values, valid range, and description
4. **Deploy Procedure** — numbered steps: edit config → run deploy.sh → verify service active → spot-check journalctl
5. **Recovery Procedures** — symptom-first H3 subsections: one per failure mode. Each subsection: symptom description → diagnosis command → resolution command
6. **Monitoring** — how to access OpenMCT (docker compose up -d openmct bridge; browser to localhost:8080); how to read journalctl
7. **Known Limitations** — bulleted list: single chamber only, no alerts, no remote config UI, GPIO library deprecation path (RPi.GPIO → rpi-lgpio), Pi 4 only

Source: CONTEXT.md D-10 (doc content spec), RESEARCH.md Architecture Patterns (documentation pattern).

### Grower Checklist (Printable 1-Page)

Format rules — strictly enforced for print context:

- **Audience:** Non-technical grower standing near the chamber. No SSH commands. No ROS2 terminology.
- **Layout:** Two-column symptom/action table. Left column: "What you see." Right column: "What to do."
- **Font target:** 12pt minimum when printed to A4 or letter. Achievable by limiting total rows to 8–10.
- **Structure:** Title → contact info box → symptom/action table → "when to call the developer" section
- **Language:** Plain language. "The humidity display shows a red number" not "fc_sensors node raises an exception."
- **No color dependencies:** All meaning conveyed by text alone. No color-coded status indicators.

Symptom/action pairs to include (all 5 are in scope):

| What you see | What to do |
|---|---|
| Humidifier not running, humidity falling | Check power strip is plugged in and switched on. Check green light on SSR relay. |
| Humidity display shows no number (blank or "--") | Wait 60 seconds. If still blank, call developer. |
| Humidity over 90% for more than 10 minutes | Check humidifier is not stuck ON. If power strip is on, turn off power strip, call developer. |
| Dashboard (localhost:8080) not loading | On the control computer, run: `docker compose up -d openmct bridge` |
| System seems stuck / not responding | Check Pi power. If powered, SSH in and run `sudo systemctl restart fc-core`. |

Source: RESEARCH.md Architecture Patterns (grower checklist anti-pattern: not a condensed OPERATIONS.md). CONTEXT.md D-09, D-10.

## Copywriting Contract
