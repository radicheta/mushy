**5. Recovery Procedures (H2)**
H3 subsections, symptom-first per UI-SPEC:

**5.1 fc-core service not running**
Symptom: `ssh fc1 'sudo systemctl is-active fc-core'` returns `inactive` or `failed`
Diagnose: `ssh fc1 'sudo journalctl -u fc-core -n 50 --no-pager'`
Resolve: `ssh fc1 'sudo systemctl restart fc-core'`
If still failing: check `sudo journalctl -u fc-core -e` for Python tracebacks

**5.2 Sensor reading 0 or missing**
Symptom: OpenMCT shows 0% humidity or no data
Diagnose: `ssh fc1 'sudo journalctl -u fc-core --since "5 min ago" --no-pager | grep -E "SHT30|error|I2C"'`
Resolve: Check I2C bus: `ssh fc1 'sudo i2cdetect -y 1'` — should show device at 0x44
If missing: check SHT30 wiring (SDA pin 3, SCL pin 5, VCC pin 4, GND pin 6)

**5.3 Humidifier not activating**
Symptom: Humidity below setpoint but humidifier not running
Diagnose: `ssh fc1 'sudo journalctl -u fc-core --since "5 min ago" --no-pager | grep "Humidifier"'`
Check: dwell guard may be active (300s between toggles). Wait 5 minutes.
Check: power strip is plugged in and SSR green LED is visible when ON

**5.4 OpenMCT dashboard not loading**
Symptom: Browser shows blank page or connection refused at localhost:8080
Resolve: `cd /path/to/mushy && docker compose up -d openmct bridge`
Verify: `docker ps | grep mushy` — should show openmct and bridge containers

**5.5 Pi unreachable via SSH**
Symptom: `ssh fc1` times out
Check LAN: `ping 10.68.155.53`
Check VPN: `ping 172.16.10.5` (requires WireGuard wg0 up on workstation)
If Pi powered but unreachable: physical access required — check network cable, power supply

**6. Monitoring (H2)**
- Dashboard: `docker compose up -d openmct bridge` on elder-plops, then browse to `http://localhost:8080`
- Dashboard shows: humidity chart, temperature chart, CO2 chart, humidifier on/off state
- Journal logs: `ssh fc1 'sudo journalctl -u fc-core -f'` for real-time log tailing
- Quick health check: `ssh fc1 'sudo systemctl show fc-core --property=NRestarts,ActiveState,SubState'`
- Service uptime: `ssh fc1 'sudo systemctl show fc-core --property=ExecMainStartTimestamp'`

**7. Known Limitations (H2)**
Bulleted list:
- Single chamber only (FC-1) — multi-chamber support is a future phase
- No alerts or notifications — monitoring requires manual dashboard checks or SSH
- No remote configuration UI — all config changes require fc_config.yaml edit + deploy.sh
- Pi 4 only — not tested on Pi 5 or other SBCs
- GPIO library deprecation path: RPi.GPIO 0.7.1 works on Pi 4 / Ubuntu 24.04, but RPi.GPIO is deprecated upstream. Migration to rpi-lgpio may be needed for future Pi/OS versions.
- WireGuard VPN required for remote access (wg0 must be up on both Pi and workstation)
