<action>
Create `src/agents/alerter/test/eval/ingestion/compare-runs.js`. CLI shape:

```
node compare-runs.js <older.jsonl> <newer.jsonl> [--threshold 0.05]
```

Loads both JSONL files; pairs fixtures by `fixture_id`. For each pair, computes a per-fixture score (binary: actual.ok ? 1 : 0; future-friendly: if both have score numerics, use those). Flags:
- PASS->FAIL transitions (older.actual.ok && !newer.actual.ok).
- Score drop > threshold (default 0.05 = 5%).
- New fixtures present in newer but absent in older (informational; not a regression).
- Removed fixtures (informational).

Print a summary table to stdout. Exit code 0 if no regressions; exit code 1 if any regression detected. Exit code 2 on internal error (missing file, bad JSON).

Header cites Phase 41 D-06b + RESEARCH section 12.
</action>
<acceptance_criteria>
- CLI is invokable with two JSONL paths + optional --threshold
- Exit 0 on no regressions, exit 1 on regression, exit 2 on internal error
- Summary table has columns: fixture_id, older_ok, newer_ok, delta, status (PASS|REGRESSION|NEW|REMOVED)
- New / removed fixtures are informational not regressions
- No em-dashes; fmtNum on the delta
</acceptance_criteria>
</task>
