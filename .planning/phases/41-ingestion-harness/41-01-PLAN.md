```js
function createJsonlWriter({ corpus, baseDir, runId, logger }) {
  // baseDir default: path.resolve(__dirname, 'results')
  // runId default: crypto.randomBytes(4).toString('hex')
  // filename: `${corpus}-${new Date().toISOString().replace(/[:.]/g,'-')}-${runId}.jsonl`
  // Open append fd. Never truncate. mkdir -p baseDir.
  // returns { path, write(obj), close() }
}
```

`write(obj)` JSON.stringify + newline + fs.appendFileSync (sync is fine for harness; batch sizes are tens of fixtures). `close()` is a no-op for appendFileSync semantics but exists for symmetry with future streaming refactors.

A second exported helper `openRunMetadataLine({corpus, runId, model, mode, smoke, cap_usd})` returns the first line of every results file: `{ts, corpus, run_id, mode:'mock'|'live', smoke:boolean, model:string|null, cap_usd:number}`. Caller writes it as line 1 immediately after construction.
</action>

CLI shape:
```
node run-harness.js --corpus <synthetic|paper-log|audio|all> [--smoke] [--live] [--cap-usd <N>]
```

Arg parser: minimal hand-rolled (no new deps). Defaults: `corpus=synthetic`, `smoke=false`, `live=false`, `cap-usd=20`.

Dispatch table (stubbed for now; loaders land in later plans):
```js
const LOADERS = {
  synthetic: null,   // Plan 03 wires this
  'paper-log': null, // Plan 04 wires this
  audio: null,       // Plan 05 wires this
};
```

For each selected corpus:
1. Resolve loader. If null, log `[harness] loader for <corpus> not yet wired (Plan NN)` and continue. Exit 0 with no-op pass when all selected loaders are null.
2. Call loader -> fixtures array.
3. If `--smoke`, slice to first `EVAL_SMOKE_SIZE || 5` fixtures.
4. Open JSONL writer (Task 2).
5. Write run metadata line.
6. Instantiate extractor + transcribe via factories: mocked unless `--live`.
7. Loop fixtures (Phase 38 elapsed-time logging style). Per fixture: call pipeline orchestration with mock attachments (Plan 02 wires the orchestration adapter; for now, just write a stub result line `{fixture_id, status:'pending-plan-02'}` to JSONL).
8. Track accumulated cost (zero in mock mode). If `--live` and cost > `cap-usd`, abort with `[harness] cost cap exceeded (cap=$N, spent=$M)`.
9. Close JSONL. Print summary line `[harness] corpus=<x> n=<N> mode=<mock|live> jsonl=<path>`.

Exit code 0 on completion, 1 on cap-exceeded, 2 on internal error.
</action>
