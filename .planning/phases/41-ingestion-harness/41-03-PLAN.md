```js
function loadSyntheticCorpus(dir, { logger = console } = {}) {
  // For each immediate subdir of `dir`:
  //   require input.json (Signal envelope: { sender, body, ts })
  //   require expected.json (target draft + requiredFields + ambiguous + optional session_id + optional provenance)
  //   detect optional attachment.{jpg,jpeg,png,m4a,wav,mp3} files
  //   optional mock-response.json sidecar -> passed through to mock-extractor
  //   optional mock_transcript in input.json -> passed through to mock-transcribe
  // return { name, kind:'synthetic', session_id, envelope, attachments:[{type,path}], expected }
}
```

The loader is tolerant: subdirs without `expected.json` log a WARN and are skipped (lets the operator stage half-built fixtures). The loader is strict on `input.json` (missing input.json -> throw).

Also export `loadMockSidecars(fixtures)` -> `Map<fixtureName, mockResponse>` for the mock-extractor cache, and `loadMockTranscripts(fixtures)` for mock-transcribe.
</action>
