<objective>
Port the two gate leaf units from Node, each with its deterministic unit tests: `rules.py` (the pure-function rule prefilter — `rule_positive` / `rule_negative`) and `classifier.py` (the never-throws `create_haiku_classifier` closure factory that calls Haiku via forced tool-use). Both are line-by-line translations of the Node source; the only structural changes are JS→Python idioms (regex `$` anchor, `>=` operator, `AbortSignal`→`with_options(timeout=...)`, `zod.safeParse`→pydantic `model_validate`).

Purpose: these are the two testable-in-isolation pieces of GATE-01. `rules.py` is a pure transform (no I/O, sync) and `classifier.py` is the single external-API surface (async, never-throws). Both have a direct Python analog (`pipeline.py` helpers / `transcribe_client.py`) so the port is mechanical. Three Node fidelity traps are called out explicitly because unit tests would otherwise pass while silently diverging from Node: the `>= 40` cutoff, the ACK_RE `$` anchor, and the timeout-as-request-option (the live bug from 2026-05-23).
Output: `rules.py`, `classifier.py`, and their two test files, all green.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| farmer Signal message (env_ctx.text/transcript) → Anthropic API | Untrusted farmer text crosses into the LLM request; must be a separate user turn, never in the system prompt |
| Anthropic API response → pipeline | Tool-use output is untrusted until pydantic-validated |
| classifier logs → operator | Logs must not leak farmer PII or the API key |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-44-04-01 | Tampering (prompt injection) | build_classifier_input | mitigate | farmer text is wrapped as a single compact-JSON user message block; CACHEABLE_SYSTEM_BLOCKS is never string-interpolated with env_ctx — separate `messages` entry, asserted in test_gate_classifier |
| T-59-02-01 | Information Disclosure (PII) | classifier WARNING logs | mitigate | the degraded/schema_invalid WARNING logs only the exception/reason — never env_ctx["text"]/["transcript"] (Pitfall 7) |
| T-59-02-02 | Information Disclosure (API key) | injected AsyncAnthropic | mitigate | classifier receives an already-constructed client; the api_key is never referenced or logged in classifier.py (key handling stays in boot.py, Plan 03) |
| T-59-02-03 | Tampering (overconfident OOD classification) | Classification schema | mitigate | confidence is range-validated [0,1] by pydantic; the 0.7 floor in the facade (Plan 03) keeps low-confidence non-events flowing to extraction |
| T-59-02-04 | Denial of Service (hung API call) | classify closure | mitigate | per-request 2s timeout via with_options; SDK max_retries=2 set on the injected client (boot.py) |
</threat_model>
