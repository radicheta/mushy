    transition(state, event) -- pure function, no DB, no IO:
    - event:`extraction_result`:
      - If shouldAskBack(draft, perFieldConfidence, threshold) -> nextStatus = AWAITING_FARMER, side_effects=['send_ask_back']
      - Else -> nextStatus = AWAITING_FARMER, side_effects=['handoff_to_phase_39']  (Plan 39 picks this up; Plan 38 does NOT send a confirm prompt)
    - event:`farmer_replied`:
      - Increment askback_turns counter. The caller will re-run extraction with the new content (state machine doesn't extract -- it judges outcomes).
      - This branch transitions IN to a re-extraction; status remains awaiting_farmer briefly while extractor runs; transition is called AGAIN with extraction_result event afterward.
      - If askback_turns + 1 > MAX_ASKBACK_TURNS AND next extraction still triggers ask-back -> nextStatus = NEEDS_REVIEW, side_effects=['send_needs_review_ping'], reason='askback_cap'
    - event:`idle_check`:
      - If now_ms - last_updated_at_ms > DRAFT_IDLE_GAP_MIN * 60 * 1000 AND status in {pending, awaiting_farmer} -> nextStatus = EXPIRED, side_effects=['mark_expired'], reason='idle_gap'
      - Else -> noop

    shouldAskBack(draft, perFieldConfidence, threshold):
    - Look up REQUIRED_FIELDS[draft.type].
    - For each required field: if missing from draft OR perFieldConfidence[field] < threshold -> return {askBack: true, missingFields: [...], lowConfFields: [...]}.
    - Special case observation: requires at least one of {state, notes} (PATTERNS notes this).
    - Return {askBack: false} otherwise.

    forceStartNewIfIdle(prevDraft, nowMs, idleGapMin):
    - Pure helper: if prevDraft && nowMs - prevDraft.last_updated_at_ms > idleGapMin*60000 -> return 'start_new'. Else null. (D-01a hard guard.)

    Export: {transition, shouldAskBack, forceStartNewIfIdle, DRAFT_STATUS, REQUIRED_FIELDS}.
