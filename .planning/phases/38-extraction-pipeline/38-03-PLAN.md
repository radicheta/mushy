## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-38-03-01 | Information disclosure | extractor.js (API key) | mitigate | ANTHROPIC_API_KEY passed only into `new Anthropic({apiKey})`; never logged. Test asserts no call to logger contains the key string. |
| T-38-03-02 | Tampering | LLM tool input -> Draft schema | mitigate | Zod safeParse with `.strict()` schemas (Plan 01) rejects off-schema; one retry with tool_result is_error=true; final fail -> {ok:false, reason:'schema_invalid'} surfaces to caller for needs_review. |
| T-38-03-03 | DoS | Oversized image -> Anthropic 413 / cost spike | mitigate | downscaleIfNeeded enforces 5MB / 1.15MP ceiling (RESEARCH Pitfall 3). |
| T-38-03-04 | Tampering | Image path traversal | mitigate | multimodal.readImageToBase64 only reads paths from signal_capture.attachment_paths (server-controlled per Phase 25 V12 ALLOWED_ROOT pattern); no user-supplied path leaks here. |
| T-38-03-05 | Repudiation | Continuity decision recorded only in LLM-generated `continuity_reason` | accept | We log the reason to signal_draft audit fields; full Anthropic request/response not logged (cost + PII). |
