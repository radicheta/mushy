<objective>
Add the on-die SHT30 heater periodic cycle in fc_sensors.py — the load-bearing piece of phase 999.34.

Purpose: Periodic heater clears membrane condensation that causes SHT30 RH creep at sustained >90% RH. The non-negotiable design choice is **race-by-construction**: fc_sensors must NOT publish poisoned slot-1 readings during the heat+recovery window. The controller must literally never see the dip — not "see it and ignore it." This eliminates the topic-async race documented in RESEARCH Pitfall 2 and live-tested at 22:02 UTC 2026-05-04 (PID spiked 0→0.85 in response to the synthetic dip).

Output: Working scheduler + state machine + Bool topic + sensor_health KeyValues + unit tests. Feature behind `heater_cycle_enabled` flag (default true on this branch; flip to false for clean rollback).
</objective>
