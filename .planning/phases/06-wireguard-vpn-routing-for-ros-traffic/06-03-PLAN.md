    **Step 1: Install ROS2 Jazzy on elder-plops**

    Elder-plops does NOT have ROS2 installed (`/opt/ros/jazzy/` is absent). Install ros-base plus CycloneDDS:
    ```bash
    # Add ROS2 apt repository if not present
    sudo apt update && sudo apt install -y software-properties-common curl
    sudo curl -sSL https://raw.githubusercontent.com/ros/rosdistro/master/ros.key -o /usr/share/keyrings/ros-archive-keyring.gpg
    echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/ros-archive-keyring.gpg] http://packages.ros.org/ros2/ubuntu $(. /etc/os-release && echo $UBUNTU_CODENAME) main" | sudo tee /etc/apt/sources.list.d/ros2.list > /dev/null
    sudo apt update
    sudo apt install -y ros-jazzy-ros-base ros-jazzy-rmw-cyclonedds-cpp
    ```

    Verify: `source /opt/ros/jazzy/setup.bash && ros2 --version` should output a version string.

    **Step 2: Install CycloneDDS RMW on Pi**

    ```bash
    ssh fc1 "sudo apt install -y ros-jazzy-rmw-cyclonedds-cpp"
    ```

    Verify: `ssh fc1 "dpkg -l ros-jazzy-rmw-cyclonedds-cpp"` exits 0.

    **Step 3: Create CycloneDDS unicast XML config in repo**

    Create `scripts/pi-deploy/cyclonedds.xml` with this EXACT content (verified from ros2 official examples). CRITICAL: Only ONE `<NetworkInterface>` entry — multiple entries break unicast SPDP. AllowMulticast MUST be false.

    ```xml
    <?xml version="1.0" encoding="UTF-8"?>
    <CycloneDDS xmlns="https://cdds.io/config"
        xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
        xsi:schemaLocation="https://cdds.io/config https://raw.githubusercontent.com/eclipse-cyclonedds/cyclonedds/master/etc/cyclonedds.xsd">
        <Domain Id="any">
            <General>
                <Interfaces>
                    <NetworkInterface name="wg0" multicast="false" />
                </Interfaces>
                <AllowMulticast>false</AllowMulticast>
            </General>
            <Discovery>
                <Peers>
                    <Peer address="172.16.10.3"/>  <!-- elder-plops -->
                    <Peer address="172.16.10.5"/>  <!-- FC-1 Pi -->
                </Peers>
            </Discovery>
        </Domain>
    </CycloneDDS>
    ```

    **Step 4: Deploy CycloneDDS XML to both machines**

    On Pi:
    ```bash
    scp scripts/pi-deploy/cyclonedds.xml fc1:/tmp/cyclonedds.xml
    ssh fc1 "sudo cp /tmp/cyclonedds.xml /etc/cyclonedds.xml"
    ```

    On elder-plops:
    ```bash
    mkdir -p ~/.config
    cp scripts/pi-deploy/cyclonedds.xml ~/.config/cyclonedds.xml
    ```

    **Step 5: Update fc-core.service with CycloneDDS env vars**

    Edit `scripts/pi-deploy/fc-core.service` to add TWO new Environment lines in the [Service] section, AFTER the existing `ROS_LOCALHOST_ONLY` line:
    ```ini
    Environment="RMW_IMPLEMENTATION=rmw_cyclonedds_cpp"
    Environment="CYCLONEDDS_URI=file:///etc/cyclonedds.xml"
    ```

    Do NOT change the After= line — per D-11, fc-core must NOT depend on wg-quick@wg0.service. Keep `After=network-online.target` only.

    Deploy the updated service file to Pi:
    ```bash
    scp scripts/pi-deploy/fc-core.service fc1:/tmp/fc-core.service
    ssh fc1 "sudo cp /tmp/fc-core.service /etc/systemd/system/fc-core.service && sudo systemctl daemon-reload && sudo systemctl restart fc-core"
    ```

    **Step 6: Configure elder-plops shell environment**

    Add to `~/.bashrc` (or the appropriate shell rc file) if not already present:
    ```bash
    # ROS2 CycloneDDS over WireGuard VPN
    export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp
    export CYCLONEDDS_URI=file:///home/santi/.config/cyclonedds.xml
    ```

    Also export `ROS_DOMAIN_ID=69` if not already set (must match Pi).
