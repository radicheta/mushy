    2. Generate keypair if not already present:
       ```bash
       if [ ! -f /etc/wireguard/private.key ]; then
         wg genkey | sudo tee /etc/wireguard/private.key | wg pubkey | sudo tee /etc/wireguard/public.key
         sudo chmod 600 /etc/wireguard/private.key
       fi
       ```
    3. Create /etc/wireguard/wg0.conf with these EXACT values (no envsubst needed — hardcode for reliability):
       ```ini
       [Interface]
       PrivateKey = <read from /etc/wireguard/private.key>
       Address = 172.16.10.5/24
       ListenPort = 51820

       [Peer]
       PublicKey = FkNbdYtcfBgsYvOzv6UcnxPIhwRDEyv8jMehsOL43E0=
       AllowedIPs = 172.16.10.0/24
       Endpoint = 10.68.155.1:51820
       PersistentKeepalive = 25
       ```
       Note: Endpoint is `10.68.155.1` (LAN pfSense IP), NOT `mossrock.space` — DNS setup is deferred per user decision.
    4. Set permissions: `sudo chmod 600 /etc/wireguard/wg0.conf`
    5. Enable and start the service: `sudo systemctl enable --now wg-quick@wg0`
    6. Print the public key at the end (needed for pfSense peer registration in Plan 02):
       `echo "=== Pi public key (add to pfSense): ===" && sudo cat /etc/wireguard/public.key`
