**1. Create `scripts/pi-deploy/deploy.sh`** — per D-04 (rsync + colcon rebuild on Pi):

```bash
#!/usr/bin/env bash
set -euo pipefail

# Configuration
PI_HOST="${PI_HOST:-fc1}"
PI_USER="${PI_USER:-ubuntu}"
PI_WS="/home/${PI_USER}/mushroom_farm_ws"
REPO_ROOT="$(cd "$(dirname "$0")/../.." && pwd)"

echo "=== Deploying fc_core to ${PI_HOST} ==="

# Step 1: rsync source to Pi workspace
echo "[1/4] Syncing source code..."
rsync -avz --delete \
  --exclude='.git' \
  --exclude='build/' \
  --exclude='install/' \
  --exclude='log/' \
  --exclude='__pycache__' \
  "${REPO_ROOT}/src/" \
  "${PI_USER}@${PI_HOST}:${PI_WS}/src/"

# Step 2: rsync config
echo "[2/4] Syncing config..."
rsync -avz \
  "${REPO_ROOT}/src/chambers/fc-core/config/" \
  "${PI_USER}@${PI_HOST}:${PI_WS}/src/chambers/fc-core/config/"

# Step 3: Build on Pi
echo "[3/4] Building on Pi..."
ssh "${PI_HOST}" "cd ${PI_WS} && source /opt/ros/jazzy/setup.bash && colcon build --packages-select fc_core --symlink-install"

# Step 4: Restart service
echo "[4/4] Restarting fc-core service..."
ssh "${PI_HOST}" "sudo systemctl restart fc-core"

echo "=== Deploy complete. Check status: ssh ${PI_HOST} 'sudo systemctl status fc-core' ==="
```

Make the script executable: `chmod +x scripts/pi-deploy/deploy.sh`

**2. Create `scripts/pi-deploy/fc-core.service`** — per D-05 (systemd service):

```ini
[Unit]
Description=FC-1 Mushroom Farm ROS2 Control
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=ubuntu
Environment="ROS_DOMAIN_ID=69"
Environment="ROS_LOCALHOST_ONLY=0"
Environment="HOME=/home/ubuntu"
ExecStart=/bin/bash -c 'source /opt/ros/jazzy/setup.bash && source /home/ubuntu/mushroom_farm_ws/install/setup.bash && ros2 launch fc_core fc.launch.py'
Restart=on-failure
RestartSec=5
StandardOutput=journal
StandardError=journal

[Install]
WantedBy=multi-user.target
```

Key details:
- `ROS_DOMAIN_ID=69` — matches project convention for cross-machine visibility
- `ROS_LOCALHOST_ONLY=0` — allows workstation to see Pi topics
- Sources both ROS2 base and workspace setup before launching
- `Restart=on-failure` with 5-second delay per D-05
- Logs go to journald (viewable via `journalctl -u fc-core -f`)

**3. Create `docs/pi-setup/dev-workflow.md`** documenting:

```markdown
# FC-1 Development Workflow

## Prerequisites
- SSH access to Pi configured (see ssh-setup.md)
- ROS2 Jazzy installed on Pi (see ros2-install section below)

## ROS2 Installation on Pi

Run on Pi:
  sudo apt update
  sudo apt install -y ros-jazzy-desktop
  echo "source /opt/ros/jazzy/setup.bash" >> ~/.bashrc

Create workspace:
  mkdir -p ~/mushroom_farm_ws/src
  cd ~/mushroom_farm_ws
  source /opt/ros/jazzy/setup.bash
  colcon build

## Install systemd Service

From workstation:
  scp scripts/pi-deploy/fc-core.service fc1:/tmp/
  ssh fc1 "sudo cp /tmp/fc-core.service /etc/systemd/system/ && sudo systemctl daemon-reload && sudo systemctl enable fc-core"

## Deploy Cycle

One command from workstation repo root:
  ./scripts/pi-deploy/deploy.sh

This will:
1. rsync source code to Pi
2. Rebuild fc_core package on Pi
3. Restart the fc-core systemd service

## Observe Logs

  ssh fc1 "journalctl -u fc-core -f"

Or for ROS2 topics from workstation (requires ROS_DOMAIN_ID=69):
  export ROS_DOMAIN_ID=69
  export ROS_LOCALHOST_ONLY=0
  ros2 topic list
  ros2 topic echo fc/humidity

## Manual Operations

Start/stop service:
  ssh fc1 "sudo systemctl start fc-core"
  ssh fc1 "sudo systemctl stop fc-core"
  ssh fc1 "sudo systemctl status fc-core"

Rebuild manually on Pi:
  ssh fc1 "cd ~/mushroom_farm_ws && source /opt/ros/jazzy/setup.bash && colcon build --packages-select fc_core"
```
