```markdown
# MOSFET Wiring Guide — FC-1 Humidifier

## Safety First
- DISCONNECT humidifier power before wiring
- Pi must be powered OFF during wiring
- Double-check all connections before powering on
- The pull-down resistor is NOT optional — it prevents the humidifier from running uncontrolled during Pi boot/crash

## Components
- MOSFET (N-channel logic-level, e.g., IRLZ44N or IRL540N — gate threshold < 3.3V)
- 10k ohm resistor (gate pull-down)
- Humidifier power supply
- Jumper wires

## Pin Assignment
- GPIO pin: BCM 17 (physical pin 11) — this is the current hardcoded pin in fc_controller.py line 49
- Note: Phase 2 (ACTR-02) will make this configurable via fc_config.yaml

## Circuit Diagram (text)

    Pi GPIO 17 ----[wire]----+---- MOSFET Gate
                             |
                          [10k R]   <-- pull-down resistor
                             |
    Pi GND -----------------+---- MOSFET Source ---- Humidifier GND

    Humidifier +V ---- MOSFET Drain

    (Humidifier power supply positive to humidifier, negative through MOSFET to GND)

## Wiring Steps

1. **Place MOSFET** on breadboard or mount point
   - Gate (G) = left pin (facing front, flat side toward you)
   - Drain (D) = center pin
   - Source (S) = right pin
   (Verify pinout for your specific MOSFET — check datasheet)

2. **Install pull-down resistor** (CRITICAL SAFETY STEP)
   - Connect 10k ohm resistor between MOSFET Gate and Source (Gate to GND)
   - This ensures Gate is LOW (humidifier OFF) when GPIO pin is floating (boot, crash, shutdown)

3. **Connect Pi GPIO to MOSFET Gate**
   - Jumper wire from Pi GPIO 17 (physical pin 11) to MOSFET Gate

4. **Connect Pi GND to MOSFET Source**
   - Jumper wire from Pi GND (physical pin 6, 9, 14, 20, 25, 30, 34, or 39) to MOSFET Source

5. **Connect humidifier through MOSFET Drain**
   - Humidifier positive wire to power supply positive
   - Humidifier negative wire to MOSFET Drain
   - Power supply negative to MOSFET Source (shared GND)

## Verification Checklist (before power-on)
- [ ] Pull-down resistor is connected Gate-to-Source (Gate-to-GND)
- [ ] Pi GND and MOSFET Source are connected
- [ ] Pi GPIO 17 goes to MOSFET Gate (not Drain or Source)
- [ ] Humidifier power supply is LOW VOLTAGE DC (not mains AC through MOSFET)
- [ ] No loose wires or shorts visible

## Power-On Test Sequence
1. Power on Pi (humidifier power supply still OFF)
2. Run test script: `python3 test-gpio-actuator.py` (see below)
3. If test passes, connect humidifier power supply
4. Re-run test — humidifier should toggle on/off
```

```python
#!/usr/bin/env python3
"""Test GPIO actuator control for MOSFET-driven humidifier.

Run on Pi: python3 test-gpio-actuator.py
Tests GPIO pin 17 (BCM) — the humidifier MOSFET gate.
"""
import sys
import time

try:
    import RPi.GPIO as GPIO
except ImportError:
    print("ERROR: RPi.GPIO not available. Install with: pip3 install RPi.GPIO")
    sys.exit(1)

HUMIDIFIER_PIN = 17  # BCM pin number — matches fc_controller.py hardcoded value

def main():
    print(f"=== GPIO Actuator Test (pin BCM {HUMIDIFIER_PIN}) ===")
    print()

    GPIO.setmode(GPIO.BCM)
    GPIO.setwarnings(False)

    try:
        # Setup pin as output, initially LOW (humidifier OFF)
        GPIO.setup(HUMIDIFIER_PIN, GPIO.OUT, initial=GPIO.LOW)
        print(f"Pin {HUMIDIFIER_PIN} configured as OUTPUT, initial state: LOW (OFF)")
        print()

        # Test 1: Read initial state
        state = GPIO.input(HUMIDIFIER_PIN)
        print(f"Test 1 - Initial state: {'HIGH (ON)' if state else 'LOW (OFF)'}")
        assert state == 0, f"Expected LOW, got {state}"
        print("  PASS: Pin starts LOW (humidifier OFF)")
        print()

        # Test 2: Set HIGH (humidifier ON)
        print("Test 2 - Setting pin HIGH (humidifier ON)...")
        GPIO.output(HUMIDIFIER_PIN, GPIO.HIGH)
        time.sleep(0.5)
        state = GPIO.input(HUMIDIFIER_PIN)
        print(f"  Pin state: {'HIGH (ON)' if state else 'LOW (OFF)'}")
        assert state == 1, f"Expected HIGH, got {state}"
        print("  PASS: Pin is HIGH")
        print("  >>> If humidifier is connected, it should be ON now")
        print()

        # Test 3: Set LOW (humidifier OFF)
        print("Test 3 - Setting pin LOW (humidifier OFF)...")
        GPIO.output(HUMIDIFIER_PIN, GPIO.LOW)
        time.sleep(0.5)
        state = GPIO.input(HUMIDIFIER_PIN)
        print(f"  Pin state: {'HIGH (ON)' if state else 'LOW (OFF)'}")
        assert state == 0, f"Expected LOW, got {state}"
        print("  PASS: Pin is LOW")
        print("  >>> Humidifier should be OFF now")
        print()

        # Test 4: Toggle cycle (3 times, 1 second each)
        print("Test 4 - Toggle cycle (3x, 1 second each)...")
        for i in range(3):
            GPIO.output(HUMIDIFIER_PIN, GPIO.HIGH)
            print(f"  Cycle {i+1}: ON", end="", flush=True)
            time.sleep(1)
            GPIO.output(HUMIDIFIER_PIN, GPIO.LOW)
            print(" -> OFF")
            time.sleep(1)
        print("  PASS: Toggle cycle complete")
        print()

        print("=== ALL TESTS PASSED ===")
        print("GPIO actuator control verified on pin BCM", HUMIDIFIER_PIN)

    except Exception as e:
        print(f"FAILED: {e}")
        sys.exit(1)
    finally:
        GPIO.output(HUMIDIFIER_PIN, GPIO.LOW)  # Safety: ensure OFF
        GPIO.cleanup()
        print("GPIO cleaned up (pin released, humidifier OFF)")


if __name__ == "__main__":
    main()
```
