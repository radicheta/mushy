<objective>
Extend the Mission Control bridge (`src/mission-control/bridge/src/index.js`) so the new health panel (Plan 02) has every signal it needs on the live stack.

Three concrete changes:
1. Forward `/fc1/sensor_health` (DiagnosticStatus, TRANSIENT_LOCAL QoS) to all connected WebSocket clients as a `sensor_health` broadcast payload. Phase 15 publishes this topic; nothing currently ferries it to the browser.
2. Add `ros.connected` to the `/health` JSON response. `true` when the rclnodejs node has finished `init().then(...)` startup and is spinning; `false` otherwise (bridge process up but ROS not yet ready).
3. Track the last time a `/fc1/actuators/humidifier` message arrived and expose `humidifier.last_msg_ts` (ms epoch, or null) in `/health`. Plan 02's Humidifier light uses this for the 30s liveness window (D-01 light #3).

Purpose: every new light in Plan 02 must consume a signal that already exists on the live stack — this plan makes them exist.
Output: one modified file, one openmct/bridge-visible behavioral change, plus a rebuilt `bridge` container on elder-plops.

```javascript
// Phase 16: forward /fc1/sensor_health (DiagnosticStatus, TRANSIENT_LOCAL) to WS clients
const sensorHealthQos = new rclnodejs.QoS(
    rclnodejs.QoS.HistoryPolicy.RMW_QOS_POLICY_HISTORY_KEEP_LAST,
    1,
    rclnodejs.QoS.ReliabilityPolicy.RMW_QOS_POLICY_RELIABILITY_RELIABLE,
    rclnodejs.QoS.DurabilityPolicy.RMW_QOS_POLICY_DURABILITY_TRANSIENT_LOCAL,
    rclnodejs.QoS.LivelinessPolicy.RMW_QOS_POLICY_LIVELINESS_SYSTEM_DEFAULT,
    false
);
node.createSubscription(
    'diagnostic_msgs/msg/DiagnosticStatus',
    '/fc1/sensor_health',
    { qos: sensorHealthQos },
    (msg) => {
        // Flatten KeyValue[] into a plain object for easy browser consumption
        const values = {};
        (msg.values || []).forEach((kv) => { values[kv.key] = kv.value; });
        broadcast({
            sensor_health: {
                level: msg.level,           // 0=OK, 1=WARN, 2=ERROR
                name: msg.name,
                message: msg.message,
                values: values              // { grace_elapsed_sec, grace_total_sec, ... } when WARN
            },
            timestamp: Date.now()
        });
    }
);
console.log('[bridge] Sensor health subscription: TRANSIENT_LOCAL QoS (/fc1/sensor_health)');
```
