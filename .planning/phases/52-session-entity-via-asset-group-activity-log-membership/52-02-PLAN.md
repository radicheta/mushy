```javascript
// createGroupAssignmentLog: POST one log--activity with is_group_assignment=true.
// CREATION-ONLY for v1.10.1 (no upsert/merge). Duplicate calls on retry are
// acceptable; Phase 51's upsert-by-stable-identity layer will dedupe later.
async function createGroupAssignmentLog(client, {
  childIds,         // string[] of asset--fungi UUIDs
  sessionGroupId,   // string UUID of the asset--group
  eventDate,        // 'YYYY-MM-DD' (caller converts to epoch via shared helper)
  name,             // string, e.g. 'inoc 2026-05-22 (11 bags)'
  draftId,          // string, embedded in notes trailer
  notes,            // optional string, prefixed to draft trailer
})
  -> { ok: true, logId, http_status } | { ok: false, reason, http_status }

// deleteActivityLog: DELETE for orphan cleanup. Mirror logs/assets delete shape.
async function deleteActivityLog(client, logId)
  -> { ok: true, http_status } | { ok: false, reason, http_status? }
```

JSON:API payload shape for POST `/api/log/activity`:

```json
{
  "data": {
    "type": "log--activity",
    "attributes": {
      "name": "inoc 2026-05-22 (11 bags)",
      "timestamp": 1747872000,
      "status": "done",
      "is_group_assignment": true,
      "notes": { "value": "mushy:draft:<draftId>", "format": "plain_text" }
    },
    "relationships": {
      "asset": { "data": [{ "type": "asset--fungi", "id": "<childId-1>" }, ...] },
      "group": { "data": [{ "type": "asset--group", "id": "<sessionGroupId>" }] }
    }
  }
}
```

Epoch conversion: reuse `epochSecondsForDate(dateStr)` pattern from `commit-seeding-session.js:31-36` — interprets 'YYYY-MM-DD' as UTC midnight, returns epoch seconds. The handler in Plan 03 will pass the already-computed timestamp; this module accepts `eventDate` string AND computes the same epoch (so the test can verify the shape end-to-end). Use Math.floor(Date.parse(dateStr + 'T00:00:00Z')/1000).
