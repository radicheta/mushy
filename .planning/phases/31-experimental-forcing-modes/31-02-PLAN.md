<objective>
Land the entire controller-side surface for Phase 31 in one plan:

1. **Schema extension (D-01/D-02):** declare `force-condensation` + `force-evaporation` modes plus the new `force_duty` key on all four modes. ModeView gains `force_duty` field; non-force modes report NaN.

2. **Force-duty short-circuit (D-02):** when `mode.force_duty` is finite, control_loop bypasses PID + Mode C entirely and emits the literal duty value to the slow-PWM driver. PID is parked via `set_auto_mode(False)` so the integrator doesn't accumulate; bumpless re-engage on revert (D-12 carry-over from Phase 28).

3. **Service-only entry (D-03):** validator rejects a direct `set_parameters('active_mode', 'force-*')` call unless the orchestrating code is the start_experiment service handler (gated by an internal flag). Plain `/fc_controller/set_mode` cannot enter a force mode without a TTL.

4. **start_experiment + cancel_experiment service handlers (D-10/D-11/D-13):** validate per D-11, allocate the ActiveExperiment record, fire the in-process mode swap, publish current_mode with `source='experiment'`, publish experiment_event with `event='started'`.

5. **1Hz TTL timer (D-05/D-06):** monotonic-clock check; on expiry perform auto-revert (set_parameters back to prior_mode, bumpless re-engage, clear active_experiment, publish current_mode `source='experiment_revert'`, publish experiment_event `event='ended'`).

6. **Boot-recovery (D-09):** on `__init__`, never come up running a force mode. If overlay-carried active_mode is a force-*, force back to a safe baseline and emit a `truncated` experiment_event so the bridge can close the row.

7. **Phase 30 interaction (D-08):** scheduler tick early-outs during a live experiment.

8. **experiment_event topic:** TRANSIENT_LOCAL JSON-in-String (Phase 29-07 precedent — avoids fc_msgs build on the bridge image). Bridge subscribes in Plan 31-03.

9. **Tests:** TDD where the controller logic is non-trivial (TTL, boot-recovery, validator gate, force_duty short-circuit, scheduler suppression).

Output: rebuilt fc_core package; the controller can engage and auto-revert force experiments; bridge endpoints (Plan 31-03) wire in next.
